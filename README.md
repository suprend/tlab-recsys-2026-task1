# T-Lab RecSys 2026, задача 1: обыгрывает ли автоматическая генерация признаков ручной бустинг

**Сдача:** [отчёт в PDF](docs/writeup/REPORT.pdf) (7 страниц), он же [в Markdown](docs/writeup/REPORT.md). Условие задачи — [docs/task1-requirements.md](docs/task1-requirements.md).

**Ответ.** В магазине REES46 рекомендуем пользователю новые для него товары. LLM-агент пишет SQL-признаки по событиям до момента рекомендации, DFS строит сетку оконных агрегатов, база — CatBoost на 80 ручных признаках. Вся автоматика без отбора — все колонки агента и DFS поверх ручных признаков (в коде и журналах — ветка H+) — дала +2.0% NDCG@20 на свежем тесте 2020, CI выше нуля [по протоколу]. Отобранное по отдельности базу не обыграло: лучший признак агента дал +0.55% (+0.0008), ниже порога шума ≈0.001, а 20 лучших колонок DFS — ниже базы на обоих тестах [по протоколу]. Вместо ручных признаков та же автоматика уступает базе: −0.77% [по протоколу]. Перенос на H&M, Tinkoff и СберМаркет, совет агентов и OTTO проверяют границы вывода; у каждого числа в отчёте стоит метка доказательности.

## Как воспроизвести

Python 3.12, зависимости закреплены в `uv.lock`:

```bash
uv sync --locked
```

Сырые данные и артефакты в Git не входят. Откуда брать REES46 и как сверить файлы — [docs/data.md](docs/data.md). Дальше по шагам:

- REES46 (тесты 2019 и 2020), перенос на H&M, Tinkoff и СберМаркет, совет агентов — [docs/task1-reproduce.md](docs/task1-reproduce.md);
- OTTO-1, OTTO-2, OTTO-3 — [docs/otto-reproduce.md](docs/otto-reproduce.md);
- ручная база H&M — [docs/hm-reproduce.md](docs/hm-reproduce.md).

Тесты запускаются из корня репозитория. Совету нужна переменная периода, его прогон идёт около 5 минут.

```bash
.venv/bin/python -m unittest discover -s tests -p 'test_*.py'
```

```bash
TASK1_PERIOD=2020 .venv/bin/python -m unittest discover -s council/tests -t .
```

Два модуля совета относятся к периоду 2019 и в этом прогоне пропускаются; их запуск:

```bash
.venv/bin/python -m unittest council.tests.test_side_task1 council.tests.test_side_task1_b
```
