# Independent metadata source audit archive

The independent source helper is preserved in [metadata_source.py](../../tests/oracles/metadata_source.py), using [row-list resolution primitives](../../tests/oracles/metadata_price.py). Its source extraction, dictionary and direct peer-list means were written independently of producer helpers. The launcher below is the actually executed audit with only portable repository/temporary paths. [Accepted measured evidence](tlab009-100q-source-verification.md) predates this path-only archival conversion; no additional execution is claimed. It requires the existing matching ignored run/source/approvals and performs no fits or target reads.

This is an audit script using assert statements, so run without Python optimization. It is not a hardened regeneration/acceptance CLI;018 currently addresses a different manual18existing-bundle scope. Metadata generalization/otherregistries require separately reviewed source oracles. A final verified producer status is not generated by this archive.
