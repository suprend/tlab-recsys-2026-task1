# Категорийные кандидаты: запуск принят, переход от C0 не подтверждён

Root принял завершённый пилот покрытия 17 октября 2026 в 08:57:37 UTC после двух независимых ACTUAL-ревью. Условие перехода не выполнено: интервалы разницы Recall пересекают ноль, а новых пар C1 нашёл 20 против 21 у C0. Текущий C0 сохраняется. Это ограниченный неопределённый результат для данной политики; он не опровергает категорийный подбор вообще. Обучения и прогнозов ранкера не было, нового NDCG или свежего final этот опыт не даёт. [Конечная приёмка Root](evidence/category-candidate-pilot/tlab-root-category-pilot-final-actual-acceptance-v1.json) и [безопасные агрегаты](evidence/category-candidate-pilot/tlab-root-category-pilot-public-aggregate-v1.json) связывают результаты с фактическим запуском.

Проверены HYP-053/HYP-032/TLAB-004 на прежнем development-пилоте: 6000 запросов, по 2000 для отсечений 8–10 октября 2019. В каждой ячейке сохранены все 121 цели fullY и 104 запроса с хотя бы одной целью, включая цели вне списка кандидатов. Из целей 73 относятся к повторным парам и 48 — к новым. C0 берёт P200+R20, C1 — P140+R20 и до 20 товаров из каждой из трёх персональных категорий. Каждый источник ограничен до объединения; совпадения удаляются, дозаполнения сверх квот нет. Полный протокол описан в [контракте](../experiments/category-candidate-pilot.md); его прежние UNRUN относятся ко времени подготовки.

Native — фактические уникальные списки каждой политики. Диагностика matched обрезает каждый собственный порядок до минимального размера пары для этого запроса, без обращения к целям. Поэтому суммы размеров native различаются; matched проверяет сравнение при одинаковом бюджете кандидатов. Macro Recall усреднён только по запросам с непустым fullY, micro — по всем целям.

Парный bootstrap по целым пользовательским кластерам, seed 2026, 1000 выборок, независимо пересчитан. Неопределённых выборок и замен выборок — 0. Для разницы positive-query macro Recall C1−C0 native Δ = +0.009615, 95% CI [−0.047619, +0.067961]; matched Δ = +0.028846, CI [−0.022989, +0.078947]. Обе границы пересекают ноль. Для заранее выбранного перехода требовались положительная нижняя native-граница и положительный native-прирост новых пар при допустимой стоимости; оба условия не выполнены. Native получил 5 целей и потерял 4, из них новые — 3 и 4. Его итог +1 обеспечен повторными парами (+2) при новых −1. Matched получил 5 и потерял 2, из них новые — 3 и 2. Положительная matched-разница не заменяет заранее выбранное native-условие.

Пустых C нет. Native C0 недобран до максимальной квоты для 5813 запросов, C1 — для 5991; в matched — 5991 в каждом arm. Это ожидаемые различия уникальных размеров после пересечений и исчерпания источников, а не доказательство одинакового фактического бюджета native. Поддержка профилей содержит 41808 ранее просмотренных товаров; missing/ambiguous — 0, все строки кандидатов имеют известную категорию в этом пилоте. Такая чистота не переносится на другие данные. U — ранее наблюдавшиеся товары, не каталог наличия или показов; новые user–item пары не означают новые для системы товары. Политика сохраняет допущение о текущей категории на последнем глобальном временном bucket до отсечения, без возврата к более старому чистому значению.

[Корректность](evidence/category-candidate-pilot/tlab-category-pilot-independent-correctness-actual-v1.md) независимо проверена по разрешённым производным Parquet: полный Q, восемь полей C0 на 1226268 строках, все 2232807 native-позиции NEXT UNSEEN round-robin, квоты и все matched-префиксы. Пересчитаны все четыре ячейки, 24000 строк query×cell, 12000 query×cohort счётчиков, 16 изменённых целей и bootstrap; поддержанных дефектов нет. Первое полное EXCEPT ALL не уложилось в память самого reader при 1 GB и завершилось ошибкой; сохранённая повторная проверка порциями по 100 Q охватила весь набор и прошла за 21.16 с. Producer не перезапускался. Это независимая проверка производных данных; исходные события, истинность последнего bucket, число distinct покупателей и исторический порядок «seal до Y» поддержаны исходным кодом/producer, а не вторым независимым чтением событий. В Root-приёмке заново проверены 145 типизированных входных ссылок; [14 установленных синтетических тестов](evidence/category-candidate-pilot/tlab-root-category-installed-tests-v1.json) прошли.
