[boosting options](https://raw.githubusercontent.com/catboost/catboost/v1.2.10/catboost/private/libs/options/boosting_options.h), [get_all_params docs](https://catboost.ai/docs/en/concepts/python-reference_catboostclassifier_get_all_params). |

Границы proof: feature_id/order/count — schema evidence, не доказательство фактического fit на expected matrix/weights. Native get_all_params не восстанавливает per-row training weights или original CPU usage/thread cap; для этого остаются reviewed fit code/input witnesses/receipts. `model_info.params.iterations` не заменяет actual tree_count. JSON `scale_and_bias` — часть prediction semantics; текущий observer использует native CBM replay, поэтому не должен вручную суммировать leaf_values, игнорируя scale/bias. Бounded score tolerance отдельно от exact ranking equality уже предусмотрена.

Наиболее полезные **существующие synthetic format obligations**, без исполнения здесь: named all-numeric layout с constant/unused last column сохраняет ordered entry с empty borders; depth0 tree/null splits не ломает inspector; shrink оставляет original iterations в metadata при smaller tree_count; отсутствие thread_count в get_all_params не выдаётся за снятый resource cap; перестановка feature_id/flat indices и чужое extra feature отвергаются. Это уточнение existing observer/API tests, не новый native fit, task или бюджет.

Некоторые auxiliary raw source URLs вернули cache miss; они не использованы как evidence. Readable implementations, указанные выше, позволили проследить нужную цепочку. Local model artifacts не инспектировались; runtime compatibility/actual output proof остаются отдельными gates.
