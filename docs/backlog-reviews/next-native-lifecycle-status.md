**Остаются непроверенными успешное обучение из свежего Python-процесса и прерывание реального native callback.** Два независимых SOURCE-предложения и [отдельный критик](evidence/next-native-lifecycle/originals/tlab-next-native-lifecycle-SOURCE-skeptic-v1.md) приняты [условно, только как проектирование](evidence/next-native-lifecycle/originals/tlab-root-next-native-lifecycle-source-adoption-v1.json). [Первое предложение](evidence/next-native-lifecycle/originals/tlab-next-cold-start-SOURCE-FIRST-v1.md) различает свежий Python-процесс и очищенный OS cache. Необязательный zero-fit отрицательный пример должен дойти до настоящего load_runtime и отказать на точно заданном отсутствующем acceptance-файле; ожидается failed/FileNotFoundError с fit_attempt_count 0. Отказ до загрузки runtime или отсутствие отчёта из-за startup failure не доказывают этот маршрут. Такой пример не равен успешному cold обучению и не добавляется третьим случаем к будущему bundle.

[Второе предложение](evidence/next-native-lifecycle/originals/tlab-next-callback-abort-SOURCE-FIRST-v1.md) предусматривает инструментированную инъекцию retained TimeoutError после обычного guard в первом фактическом native callback. Нужно сохранить исходный callback, отказ False, идентичность первичной ошибки через helper и failed CLI report; selection, copy, save/reload и продвигаемых артефактов быть не должно. Публичное partial tree_count — только безопасно доступная диагностика либо UNKNOWN. Это ещё не выполненный fault test и не полностью неинструментированный shell.

Root выбрал подготовку двух частных контроллеров: успешный cold CLI и callback-abort, затем независимое SOURCE review. Будущий общий предел **100 секунд CPU / 65 секунд wall, два свежих процесса, не более двух исходных fit по 8 деревьев** — только негрантованный черновик; достаточность неизвестна. Контроллеры находятся в подготовке, их исходники здесь не включены. Вопрос пользователю, issue, runtime и новый grant отсутствуют. Actual cold/callback **UNRUN**. Предыдущее разрешение израсходовано и закрыто: 0 попыток, остаток секунд не переносится.
