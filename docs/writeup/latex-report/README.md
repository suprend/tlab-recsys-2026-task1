# Отчёт: REES46 и OTTO

Редакция от 25.10.2026. Основная контролируемая проверка проведена на REES46. OTTO описан как отдельная исследовательская серия. Разделы переноса на другие наборы и совета агентов исключены из PDF. Журналы экспериментов сохранены в репозитории.

## Состав

- [main.pdf](main.pdf): актуальный экспорт, 5 страниц.
- `main.tex`: исходный текст.
- `REPORT.pdf`: предыдущий экспорт; после редактуры `main.tex` он не обновлялся. Актуален исходник и его текущий предпросмотр в редакторе.
- `images/otto-iterations.pdf`: векторный график private.
- `table-values.json`: неокруглённые средние для таблицы REES46 с хешами исходных локальных файлов; нужны, чтобы избежать двойного округления сводки.
- `generate_figure.py`: воспроизведение графика (Python и matplotlib).
- `fonts/`: CMU Serif для текущего текста и DejaVu для прежнего оформления; лицензии сохранены рядом. CMU загружен из https://mirrors.ctan.org/fonts/cm-unicode.zip.

## Сборка

Открыть эту папку в LaTeX-редакторе Codex. Главный файл: `main.tex`.

Для самостоятельной сборки из этой папки:

```sh
tectonic main.tex
```

Команда создаёт `main.pdf`, но не обновляет сохранённый `REPORT.pdf`. Перед передачей PDF нужно собрать текущий исходник. Можно также использовать XeLaTeX. Шрифты подключаются относительно проекта; системные шрифты не требуются.

## Редактура ясности

Текущий `main.pdf` пересобран из `main.tex`; все четыре страницы просмотрены. Вступление объясняет исследовательский вопрос и роль двух наборов данных; переходы связывают эксперименты с проверяемыми вопросами. Оформление соответствует образцу KION: CMU Serif 11 pt, поля 24 мм, абзацный отступ 6 мм, нумерованные разделы и чёрные ссылки. Убраны повторные выводы и дублирование чисел; таблица REES46 показывает результаты, изменения OTTO описаны в тексте, график показывает последовательность private-оценок. Уточнено, что основной результат REES46 относится к совместному набору агента и DFS. Округления сверены с сохранёнными метриками по запросам.

## Актуальные проверки

Исходник проверяется встроенным компилятором редактора. Полный повтор экспериментов при редактуре не запускался. Числа таблицы извлечены из сохранённых метрик по запросам; сами parquet-файлы остаются локальными. Для проверки сохранённых таблиц и последующих анализов без данных и сторонних библиотек: `python3 -I scripts/check_report.py` из корня репозитория. Эта проверка сверяет планы, хеши доступного кода, популяции и интервалы, но не пересчитывает метрики и не проверяет вид PDF. [Маршрут личной проверки](../human-review.md) связывает ключевые выводы с источниками.
