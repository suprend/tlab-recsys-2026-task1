# Весь набор агента без DFS: дополнительный разбор теста 2020

План составлен после знакомства с исходным тестом и валидацией. Это дополнительный анализ, а не новый независимый тест. Первоначальная таблица результатов не менялась.

## Результат

| Вариант | NDCG@20, среднее двух seed |
|---|---:|
| База | 0.146233 |
| База + весь набор агента без DFS | 0.149139 |
| База + весь набор агента и DFS | 0.149221 |

Без DFS прирост к базе составил 1.99%. В обоих seed интервал прироста выше нуля. Добавка DFS мала, её интервалы включают ноль; это не доказывает равенства вариантов или бесполезности DFS.

| Сравнение | Seed модели | Прирост NDCG@20 | 95%-й интервал по пользователям |
|---|---:|---:|---|
| Агент без DFS минус база | 2026 | +0.002940 | [+0.002360; +0.003495] |
| Добавка DFS к агенту | 2026 | +0.000132 | [-0.000320; +0.000568] |
| Агент без DFS минус база | 7 | +0.002871 | [+0.002308; +0.003455] |
| Добавка DFS к агенту | 7 | +0.000032 | [-0.000413; +0.000464] |

Интервалы рассчитаны отдельно для каждого сравнения и seed: 2000 повторных выборок пользователей, среднее взвешено по запросам. Это не одновременные интервалы для всех сравнений и не оценка повторяемости поиска агента.

## Что сравнивали

`Hag` содержит 80 базовых и 66 дополнительных признаков из всех 30 таблиц агента. Полный набор `Hp` объединяет базу, весь набор агента и DFS. Для `Hag` из него исключены только четыре таблицы DFS со 128 признаками. Кандидаты, исходные таблицы, настройки, два seed и лимит обучения сохранены. Новых вызовов LLM и подбора параметров не было.

Каждая модель обучалась на 140680 запросах и 7136760 строках. Оценка содержит 97656 запросов, 79302 пользователей и 14 дней; исключения 27 и 28 февраля взяты из первоначального плана. До исключения дней проверено полное совпадение запросов и масок покупочных метрик.

Чтение готовых признаков, обучение и оценка двух моделей заняли 1593 секунды, около 26.6 минуты. Расчёт признаков не входит в этот замер.

## Источники и проверка

- [План](plan.json) фиксирует настройки, входы и код до обучения.
- [Результат](results.json) содержит оба seed, все средние и интервалы, контрольные суммы входов и выходов.
- [Независимая сверка](verification.json) воспроизвела средние и интервалы до 1e-14 отдельным расчётом DuckDB/NumPy.
- [Скрипт](../../../scripts/rees_agent_test_ablation.py) обучает только новый вариант; [тесты](../../../tests/test_rees_agent_test_ablation.py) проверяют условия сравнения.

Из корня репозитория `python3 -I scripts/check_report.py` проверяет согласованность сохранённых материалов без чтения исходных данных. Он не повторяет обучение или bootstrap.

## Повтор вычислений

План и скрипт рассчитаны на аудит исходных локальных артефактов. Перед обучением проверяются SHA файлов метрик, версии библиотек, код обучения и оценки, а также прежний fingerprint подготовленных таблиц. Этот fingerprint включает пути, размеры и время изменения файлов. Поэтому даже побайтно одинаковая копия таблиц с другими временами изменения может не пройти проверку. Сырые данные и `artifacts/` не входят в Git. Воспроизведение этой проверки с нуля в чистом клоне не подтверждено.

Для повторного запуска на сохранившихся исходных артефактах нужны **новые** пути плана и выходного каталога. Следующий пример допустим, только если оба пути ещё отсутствуют. Команды выполняются из корня репозитория в прежнем окружении:

```bash
TASK1_PERIOD=2020 .venv/bin/python -m scripts.rees_agent_test_ablation \
  --prepare-plan \
  --plan docs/writeup/agent-test-ablation-replay/plan.json \
  --output-dir artifacts/task1/agent-test-ablation-replay
```

После подготовки прочитайте план: в нём должны остаться только `Hag`, два прежних seed и сравнения `Hag-base` и `Hp-Hag`. Подготовка плана не обучает модели. Затем запустите тот же план:

```bash
TASK1_PERIOD=2020 .venv/bin/python -m scripts.rees_agent_test_ablation \
  --plan docs/writeup/agent-test-ablation-replay/plan.json \
  --output-dir artifacts/task1/agent-test-ablation-replay
```

Скрипт откажется работать с существующим выходным каталогом. Повтор исходной команды с опубликованным планом не продолжает и не перезаписывает завершённый запуск. Если исходные таблицы пересозданы или fingerprint не совпадает, не меняйте сохранённые контрольные суммы ради запуска. Такой повтор потребует отдельного плана с обоснованием сопоставимости новых артефактов; текущая инструкция его не реализует и не считает подтверждённым воспроизведением исходного опыта.
