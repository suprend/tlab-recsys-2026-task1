# Отчёт и подтверждающие материалы

Актуальная версия: [PDF](latex-report/main.pdf) и [исходник LaTeX](latex-report/main.tex). PDF пересобран и визуально проверен после последних правок. Сохранённые [REPORT.pdf](REPORT.pdf) и [latex-report/REPORT.pdf](latex-report/REPORT.pdf) содержат предыдущие редакции.

## С чего начать

| Задача | Материал |
|---|---|
| Прочитать отчёт | [Актуальный PDF](latex-report/main.pdf), [исходник](latex-report/main.tex) |
| Проверить выводы и источники | [Маршрут личной проверки](human-review.md) |
| Найти первичные результаты REES46 | [План теста](../../task1/runs/replication-2020/spec.md), [результат](../../task1/runs/replication-2020/test.json), [точные значения таблицы](latex-report/table-values.json) |
| Найти оценки OTTO | [Исходная оценка OTTO-2](../otto-run/otto2-kaggle-scores.csv), [три продолжения](../otto3-run/otto3-kaggle-scores.csv), [журнал](../otto3.md) |
| Проверить последующую диагностику | [Устойчивость: план](sensitivity-2026-10-25/plan.json) и [результат](sensitivity-2026-10-25/results.json); [вторичные метрики: план](secondary-2026-10-25/plan.json) и [результат](secondary-2026-10-25/results.json) |
| Проверить весь набор агента без DFS | [Дополнительный разбор теста 2020](agent-test-ablation-2026-10-25/README.md), выполненный после основной оценки |
| Повторить вычисления | Инструкции [REES46](../task1-reproduce.md) и [OTTO](../otto-reproduce.md) |

Из корня репозитория `python3 -I scripts/check_report.py` сверяет сохранённые числа, планы и доступные контрольные суммы без локальных данных. Он не повторяет обучение или расчёт метрик.

## Как читать записи проверок

| Запись | Назначение и границы |
|---|---|
| [Реестр фактов и ссылок](fact-check-2026-10-25/README.md) | Утверждения, источники, найденные проблемы и повторная проверка исправлений. Статусы относятся к указанным в реестре редакциям. |
| [review-audit.json](review-audit.json) | Журнал выполненных проверок и исправлений; отличает их от полного воспроизведения экспериментов. Уборка репозитория отражена в записи `repository_cleanup_2026_10_25`. |
| [review-package-2026-10-25.json](review-package-2026-10-25.json) | Исторический снимок состава файлов и их контрольных сумм на момент подготовки комплекта. |
| [editorial-review-2026-10-25.json](editorial-review-2026-10-25.json) | Последующие редакторские проходы и контрольные суммы изменённых файлов, связанные с предыдущим снимком. |

Снимки относятся к файлам на момент проверки. После правок нужно снова сверить контрольные суммы и записать результат. Проверка агентами не заменяет личную проверку автора.

## История

[Предыдущий Markdown-отчёт](REPORT.md) и [сводка фактов](facts.md) охватывают более широкое исследование, включая переносы и совет агентов. Они сохраняют историю исследования. Переносы и совет агентов в текущий краткий отчёт не входят. Первичные планы, SQL и результаты остаются на прежних путях; новые расчёты не должны их заменять.
