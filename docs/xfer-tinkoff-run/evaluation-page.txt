Description
Привет! Вам необходимо построить рекомендательную модель, которая будет рекомендовать новые товары для пользователей в некотором магазине. Данные были разделены на трейн/тест. Выборка для обучения доступна для вас, и вы можете использовать ее для обучения ваших моделей. Тестовые интеракции используются для подсчета метрик качества ваших рекомендаций. Разбиение выборки было произведено по времени. Обратите внимание, что тестовая выборка содержит только те товары, с которыми пользователь не взаимодействовал в период обучения.

Базовый ноутбук находится на GitHub.

На лидерборде есть пороги, по которым выставляется оценка.

Evaluation
Привет. В качестве метрики качества используется NDCG@20.
