# OTTO: журнал разработки базы B

Контракт — `docs/otto-design.md` §4. Не больше 3 итераций, только серия dev (обучение F2 → оценка F3), рука B, зерно 2026. Числа — Recall@20 по типам и Score на популяции оценки dev (300 000 сессий Q_3, `val-F3/population.json`).

## Итерация 0 — `init-base`, 23.10

- База: `configs/datasets/otto-base.json` (`init-base`, коммит до сборки складок). Кандидаты — история префикса (до 50) ∪ популярное по типам в Q_k (по 20), до 110.
- Загрузка (`otto_data.py load`): 57 с, пик RSS 9.5 ГБ, гейт 0 пройден; train 12 899 779 сессий, test 1 671 803; все aid test есть в train.
- Коллекции: train-F2 — 2 784 888 сессий после фильтров, кадр 5.0 млн строк (обучающие сессии); val-F3 — 2 224 350 сессий, кадр 13.7 млн строк; probe-F3 — пул 20 000 сессий. Каждая 4–7 с, пик ≈5 ГБ. Репетиция полного кадра B на Q_3: 93.5 млн строк, 21 с, пик 4.7 ГБ, spill 0.
- Кандидатов на сессию в среднем 42 (39–89).

| dev F3 | clicks | carts | orders | Score |
|---|---|---|---|---|
| Pop (без ранкера) | 0.3160 | 0.3089 | 0.5707 | 0.4667 |
| потолок кандидатов B | 0.3193 | 0.3149 | 0.5922 | 0.4824 |

Потолок — Σ min(20, |G ∩ C|) / Σ min(20, |G|) по типу, Score по тем же весам. Ранкер на кандидатах B выше ≈0.482 не поднимется. Источники совместной встречаемости (item×item) по контракту не входят в B: их предлагает агент (§5.1), поэтому разрыв до ориентиров ≈0.58 — это то, что должен закрыть агент.

### Ранкер на B, итерация 0 (`otto_model.py fit --base-dev it0`)

- Smoke: один fit orders на 21 признаке B + 72 шумовых колонках — 85 с, пик 2.8 ГБ, `bootstrap_type` Bayesian, N_t = 50 000.
- Fit B (3 типа) + оценка на dev F3: 180 с, пик 4.7 ГБ. Строк обучения: clicks 481 213, carts 818 266, orders 1 205 688.

| dev F3 | clicks | carts | orders | Score |

| B, YetiRank, зерно 2026 | 0.3144 | 0.3097 | 0.5890 | 0.4778 |
| Pop | 0.3160 | 0.3089 | 0.5707 | 0.4667 |
| потолок кандидатов B | 0.3193 | 0.3149 | 0.5922 | 0.4824 |

## Решение: B заморожена на итерации 0

Ранкер B берёт 0.4778 из потолка 0.4824: остаток 0.005, и его нельзя поднять признаками — только кандидатами. Разрешённые итерации B (глубины (h) и p_t, окна ≤ 7 сут) двигают потолок в пределах популярного и истории сессии; основной разрыв до ориентиров (≈0.58) — в источниках совместной встречаемости, которые по контракту предлагает агент. Ещё одна итерация B только сократила бы место агента в лимите 200 и не меняет вопроса эксперимента. Итерации 1–3 не используются; `configs/datasets/otto-base.json` (4b50037…) — замороженная база.
