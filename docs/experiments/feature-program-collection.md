The accepted005 compiler, symbolic generator and all previously sealed collections remain unchanged. Implementation and synthetic tests are ready for independent review; real execution and source acceptance remain pending.

Every daily physical output must preserve all old45 columns, values, types, keys and multiplicity. Counts are nonnegative non-null BIGINT, recency is finite positive or null, and its Boolean flag equals nullness. Physical consistency is deliberately weaker than formula correctness. The test suite changes a legal new count by one while keeping B, keys and types unchanged: physical inspection passes. Independently recomputed formulas must reject it. `verify_source_acceptance` therefore consumes an explicit reviewed source proof with exact source/input/output pins, all-pair/all12-value scope and zero mismatches, independent oracle source/evidence, and successful producer-plus-oracle lifetime receipts. A freshly resealed changed output cannot reuse the old source proof. Known failed markers are rejected before rederivation; hashes do not create source approval.
