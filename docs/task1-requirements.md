# Проверенные требования первой задачи T-Lab 2026 RecSys

15 октября 2026. Агент прочитал авторизованную страницу [первой задачи](https://edu.tbank-online.com/selection/01a10b8d-f3da-73a2-950e-5395aeccdb3d/practice/89603/task/1) через отдельную фоновую вкладку браузера. Ответ и форму сдачи не изменял. Ниже — парафраз исходного условия, не дополнительный research proposal.

- Базовая часть: воспроизводимый pipeline градиентного бустинга с хорошими ручными признаками из истории взаимодействий.
- Основная исследовательская часть: предложить автоматизацию генерации/расчёта признаков либо альтернативный метод, превосходящий хорошо настроенный boosting с признаками.
- Предложение необходимо проверить экспериментально и изложить результаты/ограничения в читаемом отчёте. GitHub-репозиторий и PDF названы допустимыми форматами.
- Данные для признаков должны предшествовать прогнозируемому timestamp. Условие явно обращает внимание на временные утечки.
- Прямые связи user-item и косвенные связи пользователя с категориальными свойствами товара входят в пространство обсуждаемых признаков. Агрегаты, окна и их отношения — примеры ручного конструирования, а не обязательная фиксированная сетка.
- Агент, создающий SQL, графовые методы и трансформер даны как направления для идей. Конкретная архитектура, loss, purchase target, horizon, dataset или обязательный LLM API не предписаны.

В интерфейсе указано закрытие практики **25 октября в 23:59**; часовой пояс в прочитанном фрагменте не указан. На странице две задачи; это чтение само по себе не подтверждает правила выбора одной из них. Исходное решение пользователя — первая задача — сохраняется.
