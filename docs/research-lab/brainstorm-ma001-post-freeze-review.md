## MA02 fails an especially cheap uniform-bank plausibility gate

Using only supplied aggregate context, at most619 of5,317,000 training candidate rows can be purchase-positive (fullY can contain off-C targets, so this is an upper bound). For a label-independent uniform4096-row memory bank, expected positives are at most `4096×619/5317000≈0.477`. Markov's inequality gives `P(at least one positive)≤0.477`, hence `P(no positives)≥0.523`; an independent rare-event approximation would give about0.621 for zero, but the bound is enough and does not need independence. A deterministic bank has no probabilistic guarantee merely because it uses IDs/hashes; these calculations apply to its declared uniform sampling/random-seed interpretation.

This is not a data measurement and does not prove every local neighbor region is empty. It does expose that “bounded label-independent bank” can make NCA predict zero everywhere before any learned-neighborhood question is tested. Do not fit that version. Alternatives require an explicit **training-label-aware support-bank** design and correct selection weights in neighbor probability aggregation, or full-neighborhood resource proof. Retaining all permitted mature positives and subsampling negatives changes the local posterior without inclusion correction; normalization only in the outer BCE is insufficient. A label-aware bank could still be valid supervised training, but is a distinct adaptation and must not borrow ModernNCA benchmark guarantees. M001-C4 has the same support concern for its4096-row pool/local32contexts.

## Additional claims to keep narrow

1. **TabM controls:** tied adapters can still diversify through independently initialized heads, so it is a partial ablation rather than a fully identical-member null. The full null ties every source of member asymmetry or uses identical gradients. Head disagreement is not calibrated uncertainty. Parameter-matched and CPU-matched comparisons answer different questions; report both counts and updates, do not relabel either as all-properties-matched.
2. **CoverageSL:** `IDCG20(|Y∩C|)/IDCG20(|Y|)` exactly rescales candidate-normalized NDCG to fullY NDCG on that query. Applying the same ratio to a nonlinear surrogate is our hypothesis, not a consequence that it optimizes fullY NDCG. It might downweight precisely the difficult queries of interest. Absent positives remain constant irrecoverable misses. Existing C2's explicit `|C|≤20→weight1` rule should carry into a merged design; MA firstdraft leaves it to fixture/design gate.
3. **KD lifecycle:** A final standalone student can legitimately train after its historical labels mature with a teacher fitted on that same mature training set, provided both artifacts are available before later evaluation predictions. This does not authorize backfilled teacher features for earlier booster anchors. M001-C1 chooses the stricter earlier-teacher/postavailability-row design to study teacher prefixes; MA04 should not silently substitute it or claim a pure age effect. In-sample teacher fitting is a model-quality/regularization concern and paid OOF may test it, not an automatic temporal leak into later evaluation.
4. **KD closure:** FullC closes the student's recommendation domain, but teacher soft targets, temperature and the relevant theoretical gain definitions must still match before importing an RCE-KD bound. Our binary purchase fullY NDCG is not automatically their teacher-relevance NDCG. FullC KL versus teacherTop20 is an intelligible empirical contrast even without invoking the theorem. Do not claim external catalog closure when C omits targets.
