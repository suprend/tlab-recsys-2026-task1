## Common experimental boundary

REES46 October 2019 has event time, view/cart/purchase, user/product/session, category/code/brand and price. It lacks impressions, orders, titles, descriptions and images. Consequently predictive synergy means association within the observed fixed-candidate task; it establishes neither product complementarity nor causal preference. Current strong control B has 41 numeric inputs. Existing R2 adds three count columns and has preliminary development gain; this draft changes neither that choice nor the CLOSED reserved-period evaluation.

Every future comparison needs its own prospectively approved development calendar, identical Q/C/full Y, mature labels, query weights, CatBoost settings, training population and scoring iteration. Primary quality is paired full-Y conditional NDCG@20; Recall@20 guardrail is −0.002, with zero-purchase queries retained in applicable estimands. Also report user support, day slices, physical columns, all search looks, actual CPU, wall time, RSS and failed attempts. Budgets below are alternative ceilings, never additive permissions. Historical development already inspected is screening-only; this proposal creates no unseen period.

All event expressions use history strictly before anchor t, excluding global timestamp peers. Fitted discretizers, search feedback and libraries must have fit cutoff and available_at before their downstream application. A learned search policy may be fitted on mature early development outcomes and then frozen before later screening; retrospective fitting cannot masquerade as an online feature available at earlier anchors. Automatic missing/support columns count against every closure cap.

## FA01 — conditional synergy selects pairs before feature expansion

**Mechanism.** Keep weak marginal parents alive when their joint signal is strong. IIFE ranks feature pairs by interaction information before applying binary transformations, with iterative downstream evaluation; its definition uses I(x;Y|z)−I(x;Y). Our proposed discrete contextual selector instead ranks τ_c=I(x;Y|z,c)−I(x;Y|c), where c is a frozen coarse activity/popularity/repeat-state partition from existing B fields. This is a proxy conditioned on three summaries, not exact conditional utility given all B. Only typed legal pairs are expanded, using a small predeclared set of dimensionless ratios or same-unit differences. [IIFE paper, 2024](https://arxiv.org/html/2409.04665v1), [author implementation](https://github.com/tomoverman/IIFE).

**Observables and units.** Candidate rows carry existing pair counts, item counts, user counts and support flags. Discrete MI is in bits; emitted ratios are dimensionless and differences retain event-count units. BIGINT IDs remain grouping keys. Bin edges fit only on an earlier prefix; undefined ratios retain NULL plus missing, never arbitrary zero.

**Novelty delta.** HYP002/059 cover generic typed search; HYP013 covers a joint residual probe. Neither specifies pair-synergy-first expansion or the survival of individually uninformative parents. A proposal merely named “MI feature selection” is rejected as insufficient novelty. The falsifiable addition is this pair-level lookahead versus a marginal-first queue under the same closure and search opportunity count.

**Counter and cheapest falsifier.** Sparse purchase labels can make entropy estimates unstable; CatBoost may already learn the interaction. First use eight literal rows containing balanced XOR and duplicated/redundant parents: marginal information is zero for XOR parents, joint information is one bit, while duplicate-parent synergy is nonpositive. Failure to retain XOR or rejection of every sparse legal pair stops the selector. This is a planned source-free fixture, not a data result.

**Matched pilot and cost.** At most 12 parent columns, 32 expanded programs, two fixed three-column bundles selected by synergy-first versus marginal-first, and two B+bundle fits. Frozen B is primary quality control; marginal-first isolates search mechanism. Ceiling: 60 actual CPU minutes including source derivation, entropy/shuffles, scoring and verification, RSS 6 GiB, 100-query source gate before scale. Reject novelty-to-quality promotion if neither arm beats B; a win over marginal-first alone is insufficient.

## FA02 — directed family migration discovers compositions

**Mechanism.** Partition typed programs into three bounded families: temporal comparisons, action-channel contrasts and cross-grain normalization. Maintain separate archives, then construct a child by composing compatible subtrees from two families. A directed donor→recipient table updates from observed gain after migration; stagnation triggers one transfer. TopoFE actually uses LLM mutation/crossover, prompt memory, adaptive transfer and redundancy filtering. The proposed local typed mutator borrows only the family topology and composition idea; it is not a reproduction of TopoFE or an LLM experiment. [TopoFE original preprint, July 2026](https://arxiv.org/html/2607.23286v1).

**Observables and units.** Past 24/168-hour user/pair/item aggregates and their declared support closures suffice. Candidate grain remains (query,user,product). For example, a recent-to-week intensity ratio may be multiplied by a dimensionless user–category share; seconds cannot be added to counts. Newly required operators need explicit compiler/oracle support before admission. Metadata is unnecessary for the first pool.

**Novelty delta.** Current016 samples a static eight-bundle grammar; HYP012 contrasts semantic, blinded and seeded proposers. FA02 changes stateful search connectivity and permits cross-family children unavailable to a restricted single-family mutation. Merely splitting independent brainstormers into three queues, or copying an existing bundle, is rejected as duplicate administration.

**Counter and cheapest falsifier.** Learned edge weights may chase noise, while equalized random migration produces the same useful children. On a literal finite grammar, exhaustively enumerate ≤64 ASTs and verify that a specified two-family target is unreachable within-family but reachable through one legal composition. Compare learned routing to uniform routing using the same evaluated children and deterministic synthetic utility; disconnected or always-identical archives stop the architecture claim.

**Matched pilot and cost.** One common 24-program pool, maximum eight paid feedback evaluations per routing policy, followed by one learned-route B+3 fit and one uniform-route B+3 fit. Feedback is one predeclared contextual-information proxy, without fitting predictors; replacing it with model validation requires a new fit ledger and is outside this proposal. B remains primary. Ceiling 90 actual CPU minutes, RSS 6 GiB, ≤6 final new columns across arms. Search/adaptive validity is exploratory; eight decisions cannot establish general superiority. Dynamic topology is deferred if the fit-free feedback criterion cannot be frozen honestly within budget.

## FA03 — shared program search across related development tasks

**Mechanism.** Search for one parameterized feature program across three predeclared category or history-support tasks, then allow one bounded local mutation. Shared scoring averages task-normalized contextual information scores from mature early-development labels, with frozen shrinkage and minimum support, so the largest category cannot dominate. This is fit-free proxy utility, not ranking gain. EMO-STA defines shared evolution, a reusable archive and subsequent task adaptation; its time-series case concerns preprocessing programs, not recommendation. Our typed search uses no LLM and needs a shared feature interface rather than arbitrary executable code. [EMO-STA original preprint, May 2026](https://arxiv.org/html/2605.22613v1).

**Observables and units.** The same count/ratio grammar takes an entity binding and a task selector as parameters. Task assignment depends on past activity or known category, never future purchases. Missing categories form their own declared support state. Output units follow the expanded AST. All tasks share the same training anchors and fixed C; later task slices are diagnostics, not three independent samples.

**Novelty delta.** HYP003 lexical transfer, HYP051 learned-space transfer and generic portability concern representations or adapters. FA03 instead learns reusable symbolic structure by optimizing several related objectives before local adaptation. A common manually chosen feature copied into all tasks is rejected as duplicate; evaluating one global score with category slices afterwards does not implement shared-then-adapt search.

**Counter and cheapest falsifier.** The tasks may be unrelated, forcing bland programs or hiding negative transfer. Use three literal tasks where two share the same formula and the third has opposite sign. Verify shared scoring, local mutation, and failure on the incompatible task. If selected support collapses to a single task or equal scores arise solely from zero positives, stop. No synthetic success predicts real transfer.

**Matched pilot and cost.** Two common initial programs evaluated on each of three tasks, followed by one local mutation per task; shared versus independent initialization uses nine task-program evaluations per policy and at most six unique programs per policy. Two final B+3 fits maximum; a single pooled CatBoost per arm serves all slices, avoiding six unbudgeted category fits. Ceiling 90 actual CPU minutes, RSS 6 GiB, nine task-program scores per policy. B and matched independent search both matter. Report worst-task loss as a guardrail and aggregate full-Y NDCG as primary; positive shared score is not automatic promotion.

## FA04 — induce reusable grammar macros from program archives

**Mechanism.** Learn typed abstractions by compressing recurring subtrees in a frozen archive, then search with macro calls that expand into ordinary audited primitives. LILO combines LLM synthesis, Stitch compression and documentation; its evaluated domains are string editing, scene reasoning and graphics. We borrow only symbolic abstraction induction, with deterministic names and no API calls. [LILO, ICLR2024 paper](https://proceedings.iclr.cc/paper_files/paper/2024/hash/819cebb05f993840e8a52d7564c5c282-Abstract-Conference.html), [author repository](https://github.com/gabegrand/lilo).

**Novelty delta and counter.** Existing016 templates and DAG sharing are hand-specified generation or execution reuse. Learned parameterized abstractions alter proposal probabilities across later tasks. Compression alone may merely rename features and artificially improve a token-depth budget. Therefore expanded primitive size, physical columns and materialization cost remain the fair units; macro-token count is only descriptive.

**Cheapest falsifier, control and cost.** Start with ≤20 literal typed ASTs, hold out one compositional family, induce ≤4 macros, and count target discovery at equal expanded-node opportunities versus the unchanged primitive grammar. Macro expansion must preserve NULL/time/unit semantics exactly. Ceiling five CPU minutes/256 MiB/zero fits for this first gate. Only if discovery improves propose two B+3 fits, ≤30 programs and ≤60 CPU minutes/6 GiB, including all archive creation costs. Primary control B plus primitive-search arm. Current eight-bundle archive may be too small: mark deferred unless the symbolic gate shows nontrivial held-family discovery. This is no claim that a compatible learned library already exists.
