# CARTE — independent FIRST B, wave055

**Решение: 0 новых идей/ID; уточнение существующей линии embeddings, без отдельной ветки.** Source-only, blind FIRST; все предложенные эксперименты UNRUN.

**Базовый audit.** REES46: девять event-fields, без titles/descriptions/images/impressions/orders. B41/W44 имеют final ΔNDCG +0.005122 с CI через0; B1189/W403 подобраны на reused22–23 после final. Native helper UNRUN, остаток CPU неизвестен. Нужен temporal ranking control, а не перенос чужого headline.

**Механизм.** CARTE превращает строку в star graph: значения — листья, имена колонок — edges; missing cells отсутствуют. FastText кодирует open-vocabulary строки/колонки; числовое значение масштабирует embedding своей колонки. Attention агрегирует контекст в центральную вершину. Contrastive pretraining использует YAGO3: original/truncated graphlets, 18.1M triples/6.3M entities; downstream повторно использует часть pretrained layers. Cross-table joint fine-tuning допускает unmatched columns, но требует сходных outcomes и использует target validation/ensemble weighting. Это перенос параметров contextual aggregation и языковой геометрии, не user/item соответствий. [Paper v2, §§3–4/A](https://arxiv.org/html/2402.16785v2).

**Граница применимости.** Наши category paths, brand/action strings могут дать лексическую опору при законном as-of разрешении. Nominal user/product/category/session IDs должны оставаться ключами: ни величина числа, ни похожее написание ID не означают сходство сущностей. Имена колонок обозначают роли, но не создают отсутствующих фактов. Row graph сам не строит временную историю взаимодействий; B41 уже требует отдельного past-only расчёта. Дата доступности конкретного YAGO/checkpoint для historical replay здесь не установлена.

**Контроль/стоимость.** Paper: 51 classification/regression datasets, random train/test splits, 32–2048 training rows, AUROC/R²; baselines получают 100 random configurations×5 folds (кроме TabPFN), CARTE — learning-rate grid. Это контроль внутри paper, не наш repeated-query/full-Y NDCG. Pretraining использует GPU, остальные paper runs —32 CPU cores; [author README](https://github.com/soda-inria/carte) показывает FastText download и10 bagged models. Нельзя считать pretrained inputs и selection бесплатными.

**Контргипотеза и конечный следующий опыт.** Возможная польза исчерпывается обычным NLP кодированием category/brand; YAGO не добавляет полезного контекста. Если embedding-направление отдельно выбрано: optional 32 invented rows,5 ID-bijections, column-order permutation, фиксированные символические embeddings,0 fits/weights/downloads. Предсказание: ID-excluding adapter сохраняет graph modulo node permutation; удаление содержательных строк меняет graph. Нарушение первого отвергает adapter. Это проверяет representation contract, не качество; польза — предотвратить ложную semantic automation.

**Dedup.** HYP012 — semantic proposer, M08 — encoder output feature, M001-C4 — labelled-context transfer; CARTE не повторяет их буквально, но «добавить pretrained embeddings» не новая гипотеза. TA-01/02/03 переносят macros/edits/routing; CARTE их не реализует. Полезное уточнение — отделить lexical transfer от nominal identity; mandatory gates/grants не добавлены.

Published benchmarks не наши результаты.
