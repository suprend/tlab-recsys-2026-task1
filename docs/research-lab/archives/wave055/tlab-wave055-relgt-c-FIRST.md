# RelGT — independent FIRST C, wave055

**Базовый аудит.** Нужно вручную определить graph user–event–item и доступность атрибутов; обучить encoders, attention, centroids и prediction head; выбрать sampling, K/L/dropout/seed. Это supervised representation learning, а не готовый бесплатный encoder. Для нашего переноса nodes, vocabulary и metadata берутся из `<T`; supervised labels должны созреть до simulated model availability `A≤T`. Scalers/weights/EMA-centroids замораживаются к A; cache привязан к cutoff, model state и sampling seed. Actual2026 seal предшествует открытию новых evaluation outcomes; 25–31 октября остаются reporting-only. Стоимость включает graph/index setup, sampling, PE, все fits/looks, failed attempts, cache и scoring полного C; CPU-остаток неизвестен. Сила контроля не следует из потолка B1189 на reused validation.

**Механизм.** Paper кодирует каждый узел пятью компонентами: attributes, table type, hop, relative time, GNN-PE со случайной инициализацией; paper time encoder — линейный `WΔt`. Двухшаговый sampling использует `≤T` и случайный fallback при нехватке соседей; это не наш строгий cutoff. Элементы конкатенируются и проецируются; локальное all-pair attention дополняется global attention к EMA-centroids. Default: 10–20M parameters, K=300, 4096 centroids; evaluation исключает recommendation. Поэтому опубликованные gains не являются нашим ranking результатом. [ICLR paper](https://proceedings.iclr.cc/paper_files/paper/2026/file/fa1ef43326cfb8a808c0649708187f2a-Paper-Conference.pdf). Авторский recipe ориентирован на CUDA/A100, CPU feasibility не установлена. Публичный time encoder использует positional encoding + linear; paper/code equivalence не установлена. [Repo](https://github.com/snap-stanford/relgt/blob/main/encoders.py).

**Перенос к цели — inference.** Возможен pair head `s(u,i,T)=MLP(h_u,h_i,h_u⊙h_i,B41)`, обучаемый на прежнем candidate-row objective. Скорить только fixed C; полный Y, включая out-of-C покупки, сохранять в NDCG/Recall denominator; empty/zero-Y queries и deterministic ties сохраняются. User-only output не задаёт ranking товаров. Новых synthetic user–candidate interaction edges не добавлять.

**Prediction/counterhypothesis.** GNN-PE может различить одинаковые B41-агрегаты при разных FK-связях и улучшить ранжирование. Контргипотеза: degree/popularity уже достаточны, sampling теряет редкие связи, глобальное состояние добавляет шум.

**Ближайший конечный опыт — UNRUN.** Шесть source-free fixtures, ≤32 придуманных строк, два anchors: одинаковые агрегаты/разные связи; future append; equal-T peers; fallback; меняющаяся category; empty C. Проверить token/adjacency различимость и past-only invariance, без fits. Это проверка представимости, не качества. Возможное последующее сравнение ограничить тремя fits: сильный заранее настроенный B41 и одинаковые compact pair models с/без GNN-PE; одинаковые Q/C/fullY, fresh outcome boundary, заранее равные CPU ceilings и полный cost ledger. Это adaptation без global module, не reproduction полного RelGT; разрешения на запуск нет.

**Дедуп/решение.** Refinement M05 attention и M08 encoder lifecycle; round048 уже покрывает RelBench temporal interface. HYP002/011 — typed program generation, отличная от learned representation. RelGT отличается от Relational Transformer в TA-03, но не отменяет его recommendation limitation. Direct transfer reject; full RelGT defer; новых ID/gates/grants нет.
