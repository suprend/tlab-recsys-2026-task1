# Wave055 — independent skeptic

**Accept исследовательские решения; refinement A/C, merge B; reject прямой перенос, defer полные архитектуры. 0 новых ID/gates/grants.** Девять FIRST/report–pins–freeze и общий context совпали по SHA на входе и после ревью; receipts показывают freeze всех трёх до critic. Это проверка артефактов, не независимое доказательство всей истории авторов.

**A / RelGNN:** механизм передан верно: fusion event/source и destination-conditioned attention устраняют конкретный двухшаговый self-return. Сравнение с matched HeteroGNN исследует механизм; raw-entity LightGBM не заменяет наш хорошо настроенный контроль. Сохранить как refinement TLAB-014/round048, без утверждения pretrained transfer или генерации aggregate columns. [v2 §§4–5, C](https://arxiv.org/html/2502.06784v2).

**B / CARTE:** star-row, языковые embeddings и YAGO-pretraining описаны верно; joint transfer требует сходных outcomes и использует target validation. Merge lexical-transfer contract в M08; HYP012 и M001-C4 относятся к другим механизмам. Числовое значение или написание nominal ID не дают business semantics; допустимые identity embeddings/PK-FK связи этим не запрещаются. Category paths/brand могут дать lexical signal, отсутствующие descriptions/images/impressions/orders — нет. [v2 §§3–4/A](https://arxiv.org/html/2402.16785v2).

**C / RelGT — одно существенное уточнение:** paper §3.1 пересэмплирует случайные **node features** GNN-PE на каждом training step; формулировка «случайная инициализация» недостаточна. Для будущего invariance witness нужны согласованные RNG draws/permutation; иначе различия могут возникнуть от случайности. Cache/replay должен учитывать PE randomness либо явно заявленную fixed-evaluation policy. Compact pair adaptation без global module не является reproduction полного RelGT; recommendation tasks исключены из benchmark. Refinement M05/M08, direct-transfer reject. [Official ICLR2026 §§3.1–3.2/A.1](https://proceedings.iclr.cc/paper_files/paper/2026/file/fa1ef43326cfb8a808c0649708187f2a-Paper-Conference.pdf).

Общий contract обязателен для любого отдельно выбранного будущего метода: `<T`, исключение **всех global timestamp peers**, maturity/model availability, past-only vocabulary/statistics/centroids и metadata resolver. PK/FK сохраняет connectivity, event keys — observational multiplicity; это не автоматически бизнес-смысл. Fixed Q/C и полный Y сохраняются; sampled-neighborhood head не должен silently удалять candidates или out-of-C positives. User-only output не задаёт ranking товаров.
