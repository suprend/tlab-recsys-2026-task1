# Wave018 A — failure-preserving reduction needs an explicit context

Independent FIRST,15 October2026; peer18 unread, no helpers. Zero new mechanisms/HYPs. This is an optional refinement of prior round018 shrinking/verification (reserved HYP-121/122), related to HYP-002/046. No framework, mandatory gate or change to015/018 is proposed; execution_scope_audit retains main ownership.

**mechanism.** For a previously failing invented bag of≤12 events, enumerate sub-bags by increasing cardinality, retaining exact nominal IDs/timestamps, NULL and raw multiplicities. Accept a reduction only when both interpreters return normally and reproduce the pinned semantic failure fingerprint: stage/operator, anchor, focal key/field, expected typed state and discrepancy class. Generic “any mismatch”, exceptions or budget failure do not qualify. Recompute the complete latest global timestamp bucket and every required denominator from each proposed bag; do not reuse metadata/support snapshots or discard off-C contributors by a syntactic dependency guess. Duplicate occurrences have reducer positions, not fictitious source event IDs.

Two contexts must remain explicit. For a conditional feature failure, fixed Q/C are declared inputs; this makes no query/retrieval regeneration claim. For a sampling/retrieval failure, recompute Q/C under the unchanged policy for every proposal and require the pinned focal failure to remain meaningful; vanished query/candidate is not the same downstream cell failure. Do not relabel one mode as the other. Never rename IDs to smaller integers: hashes and tie breaks can change.

**prediction.** A stage/state fingerprint should reduce diagnostic misattribution compared with “any disagreement” at the same reduction budget. It cannot prove a unique root cause: several defects can share the same fingerprint. A conservative fingerprint can also retain unnecessary rows or leave no smaller witness.

**nearest single finite experiment.** Completed one pure-stdlib experiment: six invented five-field event projections,64 sub-bags and128 predicate calls; no full typed9 producer, actual source, SQL/native/model/Y/fit/hash scan. The deliberately compound mutant ignores NULL in latest metadata and restricts category denominator to C. Generic reduction returns two rows with clean category20 and share1/2 versus1, losing the original ambiguity fault. The pinned metadata predicate returns the two same-second category10/NULL peers, with expected ambiguous/NULL versus mutant known10/share1. Both witnesses have size2; smaller does not mean same failure. The ledger records exact events and witnesses. These direct toy functions are independent of project producers, but not an independent proof of the actual compiler.

**task1benefit.** A smaller, stage-specific counterexample can make semantic calculation failures easier to explain and turn into existing regression fixtures. It adds diagnosis evidence rather than ranking quality, execution authority or full-source reproducibility. Mixed-NULL peers, strict endpoints and off-C denominator events must survive whenever needed by the actual pinned predicate.

**cost and strongest counterexample.** For n≤12, exhaustive deletion tests at most4096 sub-bags and8192 interpreter executions; all rejected attempts, dependency checks and serialization count. A future optional toy must stop at15CPU/30wall seconds and128MiB, without a second search allocation. Real SQL/oracle execution may be expensive and is excluded. The strongest boundary is deleting an eligible user's only event: a fixed-Q reduction can retain a feature failure even though actual bottom-hash Q changes or disappears. It therefore cannot diagnose a sampler failure. Global minimum here means only smallest allowed sub-bag for this fingerprint/context, not a minimal causal explanation or generated new event world.

**negative decision.** If fingerprint-preserving reduction is no cheaper/more informative than current literals, retain existing fixtures. If failures drift, Q/C context changes silently, or the budget expires, return the original witness plus incomplete-search evidence; do not claim minimization. No new mandatory backlog item, primary-source search or additional main-pipeline experiment is warranted.
