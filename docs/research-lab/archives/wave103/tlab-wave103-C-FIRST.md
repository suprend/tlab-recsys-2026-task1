# Волна103 — C FIRST: NEW0 / уточнение objective alignment

2026-10-17. Независимый FIRST; strongest refinement — **случайный размер будущего набора меняет желаемый порядок даже при полном coverage**. Новый HYP не предлагаю: TLAB-008/HYP035, loss-selection03 и wave028/059 уже владеют вопросом objective alignment.

**Механизм.** При одном доступном контексте X максимизатор ожидаемого NDCG ранжирует по `E[y_i/IDCG(Y)|X]`, а BCE — по `P(y_i=1|X)`. Нормировка возникает внутри ожидания. Это следует из [Ravikumar–Tewari–Yang, 2011, Lemma4/Corollary5](https://proceedings.mlr.press/v15/ravikumar11a/ravikumar11a.pdf), для фиксированного списка и произвольного совместного распределения relevance; это population characterization, не обещание finite-sample выигрыша. Для маленького свидетеля ниже K20 покрывает весь список, поэтому различие truncation не возникает.

**Аналитический свидетель, НЕ выполненный тест.** Фиксированные `C={a,b,c}`, одинаковые past features во всех реализациях будущего. Зрелый полный `Y={a}` с вероятностью0.45 либо `Y={b,c}` с вероятностью0.55. Все targets покрыты, обе реализации информативны; impressions для этого offline target не требуются. Пусть `I2=1+1/log2(3)`.

- NDCG-порядок: `a` первый, поскольку `0.45 > 0.55/I2≈0.337`.
- BCE-порядок: `b,c` выше `a`, поскольку `0.55>0.45`.
- Для полного PairLogit с суммой весов1/query обе реализации имеют две пары и вес1/2. При `s_b=s_c` минимум по `d=s_a−s_b` находится в `d=log(0.45/0.55)<0`. Значит, он также ставит `a` ниже. Это собственная алгебра по [определению PairLogit CatBoost v1.2.10, строки0–35](https://raw.githubusercontent.com/catboost/catboost/v1.2.10/catboost/docs/en/concepts/loss-functions-ranking.md), не theorem о текущем learner.

**Отличие от прежнего.** Здесь `h=|Y∩C|=|Y|=m`, поэтому множитель wave028 `I(h)/I(m)=1` в каждом исходе. Его исправление coverage-нормировки не устраняет этот контрпример. Inverse-probability correction uniform negatives лишь восстанавливает исходный BCE/PairLogit риск; она не превращает его в NDCG-риск. Это не exposure correction и не повод очищать negatives по более далёкому будущему.

**Предсказание и контргипотеза.** Перебор шести перестановок сохранит описанный противоположный порядок; при одинаковом `|Y|=1` в обеих альтернативах нормировочный переворот исчезнет. На REES46 механизм может быть практически неважен: singleton targets могут преобладать, доступные признаки различать будущие режимы либо variance/coverage/finite capacity доминировать. Реальная распространённость не прочитана и не измерена.

Никакого текущего запуска, нового gate или training recipe не предлагаю.
