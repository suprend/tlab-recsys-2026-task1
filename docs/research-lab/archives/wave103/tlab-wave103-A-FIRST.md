**Механизм A103-01.** Проверить последовательный отбор кандидатов с накопленным насыщением категории, вместо ещё одного статического перевзвешивания источников. [Kaya/Bridge, RecSys2019, §2, Eqs2/5–7 и §4](https://www.insight-centre.org/wp-content/uploads/2020/05/A-Comparison-of-Calibrated-and-Intent-Aware-Recommendations.pdf) дают остаточное произведение покрытости; это отличается от заданных пропорций. Прочитаны указанные разделы, §5.1/5.3 и §6.2; весь paper не прочитан. Random 60/20/20 split и музыкальные/кино-данные не доказывают временной purchase gain.

Своя фиксированная адаптация: один заранее замороженный distinct pre-fusion pool D, одинаковые списки/depth во всех ветвях. Защитить R20, остальные ≤200 мест выбирать из D\R20. D может включать уже заданный S20; graph/seed/source recipe не меняются. Положительный rank-only RRF score r нормировать максимумом D; h_c — доля c среди supported distinct view-products пользователя за7d: category_id последнего прошлого view; конфликт timestamp peers unsupported. Для as-of category кандидата задать q_ic=r_i/Σ_{j∈D:g(j)=c}r_j; другие категории дают0. Последний глобальный bucket строго<t, NULL/conflict unsupported. Это конструкционные веса, не вероятности покупки. Выбирать максимальный

`G(i|A)=0.5 r_i + 0.5 Σ_c h_c q_ic Π_{j∈A}(1−q_jc)`.

A содержит уже защищённые R20 и выбранные товары; ID разрешает ties. Missing category получает только базовый вклад; пустой профиль возвращает статический RRF. Никакого refill, дополнительного graph discovery или нового fitted state. Старый C0 остаётся отдельным reference. Внутри selector-контраста размер одинаков: `|R20|+min(200,|D\R20|)`.

**Различающее предсказание.** При одинаковом максимальном сходстве с уже выбранным товаром ещё один выбранный товар той же категории дополнительно уменьшает marginal score. Стандартный max-similarity MMR этого накопления не имеет. В шести-item fixture: четыре A-ID перед двумя B-ID, r=1, h=(.5,.5), protected-пул пуст, budget3. q_A=1/4,q_B=1/2: greedy берёт B1,A1,B2; static RRF — A1,A2,A3; mass-quota с largest-remainder и A-tie — A1,A2,B1. Это ручной расчёт, не выполненный тест; специально изменённый MMR может эмулировать правило, универсальная неэквивалентность не утверждается.

**Контргипотеза.** Дневной full Y может содержать несколько полезных товаров одной категории: насыщение вытеснит реальные покупки. h по просмотрам смешивает интерес/экспозицию; category — грубый proxy. q зависит от состава D: короткая категорийная очередь может получить искусственное преимущество. Разнообразие и число новых ID не означают Recall gain; увеличение глубины меняет сам опыт.
