Cite `arXiv:2602.02025v1` (2026), titled *Hippasus: Effective and Efficient Automatic Feature Augmentation for Machine Learning Tasks on Relational Data*. The arXiv-issued DOI is `10.48550/arXiv.2602.02025`; it does not select a version by itself.

The [v1 HTML header](https://arxiv.org/html/2602.02025v1) instead prints PVLDB 16(2), 356–368, 2022 and DOI `10.14778/3565816.3565835`.
