# Wave030 B FIRST — pair screening has no free utility oracle

**Disposition:** zero new IDs. Refine HYP141/FA01, HYP002/059 and own waves011/013; no current recipe, final, or main-gate change.

**Mechanism.** Test existing pair-first allocation against label-blind seeded uniform ordering of the same complete legal AST universe. IIFE computes interaction information across pairs, then evaluates transformed candidates through downstream cross-validation; it does not establish a fit-free substitute for CatBoost utility.[1] A frozen discretized screen is our cheaper adaptation. Uniform search is a baseline, not a guarantee of discovering a useful pair.[2]

**Prediction/counterexample.** Specify twelve same-unit parents and one oriented subtraction per unordered pair: 66 legal ASTs. In eight invented user-query groups with two candidates each, only group1 purchases: a has (x,y)=(1,3), b=(1,1); others have (1,1), all nonpositive. Other parents are constant. Frozen bins [0,4) erase every parent distinction, so every discretized interaction score ties at zero, while x−y separates a from b. Reverse group1's purchased item: identical past and screen scores, opposite useful ordering. This falsifies a universal screen-to-ranking guarantee, not IIFE's estimator. If B already models the raw parents' interaction, the transformation may add nothing. Rare feedback cannot resolve that by declaring the proxy correct.

**Nearest finite UNRUN falsifier.** Write these two literal outcome worlds and a predeclared tie order. Check pair enumeration, constant-bin scores, selected AST identities, expanded NULL/support closures and reversed ordering. Do not fit or simulate a CatBoost quality result. One world has 8 Q/16 C rows/1 positive group; both require at most 384 parent values and 2112 pair-row histogram updates. Record all 66 label-dependent pair scores, not merely selected children.

**Strong control/task1 benefit.** Freeze the legal grammar before labels; legality is distinct from the visited subset. Compare pair-first and uniform policies under the same total-cost ceiling and explicit feedback/fit caps, Q/C/full-Y targets, source availability, typed/time/NULL semantics, model recipe and final selection rule. Uniform need not waste saved screening time; it may explore within the same caps. Eligible B/W procedures remain quality controls on the same future context; their preparation/training/scoring costs are not free. Winning only against uniform does not establish gain over B/W. This isolates useful allocation from manual inventory or extra opportunities.

**Cost/negative outcome.** Pair discovery costs O(Np²), histogram state up to O(p²b²); dense candidate storage adds O(Np²). Charge bin fitting, complete historical prerequisites, authentication, masks, spills, all proxy/validation looks, reused-label feedback and failed fits. Labels mature before screening; bins/policy exist before application. No current experiment/grant; future reservation unknown. If uniform matches, the screen discards useful pairs, or no incremental B/W gain appears, defer HYP141 rather than expand feedback.
