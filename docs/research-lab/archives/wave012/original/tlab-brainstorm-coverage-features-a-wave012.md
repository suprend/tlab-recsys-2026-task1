## A012-R1 — compile only population-compatible pooling, preserve its parents

**mechanism.** A future compiler may instantiate a smoothing template only after proving that local and parent estimates describe the same outcome category in compatible raw-event populations. It must not treat `pair → item → category → global` as a universal numeric backoff chain: pair counts, item rates, category shares and user activity have different denominators and meanings. Numeric dtype and common count units do not suffice.

Use one already-proposed instantiation as the finite test, not a new feature family. For query user u, candidate's clean current numeric category c and the same observed portion of `[t−7d,t)`, let x be raw user/category views, N all raw user views, Cc all raw historical-category-c views and G all raw views globally. Define p=Cc/G and, with the old explicitly fixed pseudo-count α=5,

`q=(x+5p)/(N+5)`, `w=N/(N+5)`.

Here q is a smoothed **recorded-view category share**, not purchase propensity, CTR, exposure correction or a confidence bound. Its support-adaptive mixing is deterministic; the automation is legal template instantiation and physical dependency compilation. There is no learned grain router, fitted α, optimizer or outcome feedback. Current registry005 does not support the global-grain primitive/template: this is a future capability contract, never permission to insert it into015/016.

The compiler checks matching source, action, raw multiplicity, interval and availability policy; proves x⊆N, Cc⊆G and the same category predicate; and requires separate view-category mapping. For unknown current c it emits unknown conditional values, rather than silently dropping the category predicate. An item-conditioned or pair-conditioned variant would require its own outcome/population proof and cost closure; it is not admitted by this example. No taxonomy is inferred from numeric IDs.

**prediction.** Compared with raw affinity alone, q may give a fixed tree learner a convenient smooth transition between personal view composition and global category demand for rare users. It can also suppress a useful rare preference and overreact to repeated log rows. Relative to a control containing the same parents it supplies no new information. Count-based w measures algebraic mixing mass, not independent evidence; source completeness, user first-seen age and item first-seen age are different observables.

**nearest finite experiment.** A source-free interpreter should check feasible count worlds, explicit unknown/zero states, admissible and rejected grain mappings, peer/future invariance and demanded parents. Compare q with the simplest direct-prior representation under an identical mask. Actual completed literals below establish arithmetic boundaries only. A further compiler drill would allow at most16,384 small count tuples,32 invented events,8 anchors,60 CPU seconds and128 MiB; zero source/label reads, fits or metric looks. Stop on the first mismatch; do not replace failing mappings until a favorable example appears.

**task1 benefit.** This prevents the generator from spending search and scans on semantically invalid backoffs, forces support/missingness into the physical closure, and exposes when an apparently intelligent sparse-history feature is merely a reparameterization of a stronger simple control. It provides negative admission evidence; it does not show better recommendation quality or automatic choice of the most useful grain.

## Exact availability, support and NULL closure

All four counts use the identical declared observed source interval intersected with `[t−7d,t)`, including declared gaps. Report its duration E using the existing coverage field. Counts describe that observed portion; neither shrinkage nor division reconstructs the unobserved portion. E is source coverage, not user membership duration or item availability. A new/rare entity first observed yesterday does not imply one day of known exposure. No user/item registration, stock, impressions or complete catalog exists here.

At every timestamp, compute all users' queries before applying any event from that global second. Historical categories remain attached to events. Candidate c comes from the entire latest global past product timestamp bucket: known+NULL/conflict means unknown, without older-clean fallback. A missing category_code does not erase a known numeric category. G includes views with unknown category and products/users outside C; it is not the sum of requested-category totals, not the candidate-row count, and not a known-category-only denominator.

If c is known and G>0, q is defined even when N=0: q=p, w=0, explicitly prior-only. If N>0 and x=0, the raw local share is an observed zero while q can be positive. If G=0, or c is unknown/ambiguous, q and p are NULL. Unconditional N and G remain known counts; conditional x/Cc are NULL for unknown c. Known-empty counts retain0 with existing coverage flags, including E=0; G=0 then makes the pooled expression undefined. No candidate/query is removed or filled. Existing B values and their NULL conventions are untouched.

The proposed treatment emits q, G and one mask m=`unknown(c) OR G=0`; the direct-prior control emits p, G and the identical m: at most3 additional physical columns each before exact W alias review. Existing x,N,Cc, coverage and category states are reused only with a verified identical semantic contract. w is not another column because existing N determines it. q requires a different missingness condition from raw x/N, so its mask cannot automatically reuse the raw-share-missing flag. All required native encoding/masks count in closure; any unavoidable fourth column forces redesign before a trial, not a free addition. Checked exact integer counts precede declared floating calculation/float32 transport; those native paths are untested.

## Strong controls and same-count adversaries

W already contains user/category x, user N and category Cc. Thus W+G determines both p and q. Moreover, where defined, `p=(q(N+5)−x)/5`: q and p are invertible conditional on existing N,x, including N=0. Comparing against W alone could conflate the new global denominator with smoothing. The equal-closure direct-prior control is W plus p,G,m; also disclose that W+G alone is an even simpler information basis. A separate fit of that third basis would consume a third fit; none is free or proposed here. No full current-W nonalias claim is made without its exact frozen schema audit. Any gain over the direct-prior representation would be a learner/representation effect, not information creation or learned confidence.

Invented exact tests executed:

* Exhaustive feasible integer tuples with1≤G≤20,0≤Cc≤G,0≤N≤G and x bounded by both local/global category and complement masses:10,625 worlds. Bounds0≤q≤1, convex-mixture identity and inverse reconstruction all held exactly using Fraction.
* Same local numerator0: no views `(x,N,Cc,G)=(0,0,10,100)` gives q=1/10; observed other-category views `(0,5,10,100)` give q=1/20. Unknown c and G=0 give NULL. These distinguish prior-only, observed zero and unavailable context; a generic coalesce-to-zero loses them.
* Two ten-view histories share first/last timestamps, item/category assignments, all1d/7d counts and distinct items, yet occupy4 versus6 UTC dates. Both get the same w. This is a counterexample to count support determining temporal spread, not a claim that six dates are six independent samples or that full B41 cannot distinguish all possible worlds.
* A local raw bag copied once changes `(2,10,10,100)` to `(4,20,12,110)`: q changes1/6→2/11 and w2/3→4/5. Raw duplicates must remain counted; the increasing mixing mass does not prove increasing statistical reliability. Distinct users/sessions would be different support definitions, already related to FB-02 audience-shape research and requiring additional state.
* Eight invented rows at exact lower/upper boundaries, with an off-C view, repeated raw row and unknown historical category give `(G,Cc,N,x)=(6,3,4,2)`. Reversing peers or appending a future row preserves them. C-only aggregation disagrees. A latest global known+NULL metadata bucket remains unknown; older metadata cannot repair it.

These are past-observable counterexamples. No invented response labels, predictive scores or simulated quality gain were used. A count/coverage-only router sees equal supports in many worlds with different preferences or timing; universal preservation of utility is not established.
