## Source evidence and an important non-transfer

[Bifet and Gavaldà's ADWIN paper](https://www.cs.upc.edu/~gavalda/papers/adwin06.pdf), a2006 manuscript for the2007 work, motivates growing/shrinking retained history after comparing subwindow means. Its stated setting has independent bounded observations. Inspected [MOA author-project code](https://raw.githubusercontent.com/Waikato/moa/master/moa/src/main/java/moa/classifiers/core/driftdetection/ADWIN.java), `setInput`, advances an observation counter, inserts one value and tests/deletes buckets. It is not a wall-clock1/7/30d count operator. No implementation is installed or reproduced.

Feeding the value1 for every view gives mean1 whether ten views occurred in an hour or a month; event-index adaptation cannot thereby detect a wall-clock rate change. Raw event rates are also bursty, dependent and not bounded[0,1] observations. Consequently no ADWIN significance or optimality guarantee is claimed for the deterministic gate below. No fresh paper is required to rebrand this old idea. The new detail is an exact typed contract, coverage/maturity admission, demanded-parent accounting and a strong falsifier.

## A010-01 — expand a complete window only when adjacent rate bands agree

**mechanism.** Define a finite ladder W={1,7,30}days. Its operator input includes an authenticated source interval `[S,F)`, the frozen training/query calendar, label horizon H, raw-view counter semantics, exact endpoints and the approved physical emitter. First apply a calendar-only admission gate: a window must have at least two distinct predeclared training anchors with full past coverage and a whole mature label horizon. This threshold is a design/support gate, not evidence of statistical power. Do not select dates after inspecting outcomes. The allowed ladder is frozen before downstream training.

For each user/anchor, let U_w be raw user-view count on `[t−w,t)`, usable for selection only when that entire interval is covered. Completeness follows the declared source-coverage intervals, including any gaps; endpoint span alone is insufficient. The primary comparison requires full7d coverage in **both** arms; otherwise their new block is NULL with the same missingness. Keep all original Q/C/Y rows and existing B/W partial-count semantics. This separate complete-window operator does not overwrite a clipped raw counter or interpret an unobserved tail as0.

Initialize h=1d. For each next admitted and complete width w, compare the current suffix h with its disjoint older annulus `[t−w,t−h)`. Let nA=U_h, nB=U_w−U_h, a=h days and b=w−h days. Expand to w only if both counts are at least6 and

`D=abs(nA/a−nB/b)/(nA/a+nB/b) ≤ 1/3`.

Otherwise stop expansion; larger windows are not a free fallback. The gate is a fixed heuristic, **not** a stationarity test. Its thresholds are not fitted or tuned in this proposal. Implement it with checked integer arithmetic `3·abs(nA·b−nB·a) ≤ nA·b+nB·a`; supports prevent a zero denominator. Share identical user counts across all candidates of the query. A complete source window with zero recorded views is known0; it fails the support gate and leaves h=1, rather than becoming an unknown count. Source coverage is never replaced by user first-seen age.

For candidate i, emit `R_ui=P_ui,h/h_days`, where P is the exact raw pair-view count in the selected window, alongside h in hours and the required common missingness. These are registered events per covered log day, not exposure, CTR, repeat hazard or orders. Proposed closure is at most three physical columns; count actual emitted masks even when semantically derivable from existing coverage. Reuse an existing mask only through a reviewed emitter. All events are globally `<t`; same-second peers update state after the query. No category/session/impression/order field is needed. First/last-observed state and all baseline metadata remain inherited unchanged.

**Coverage/maturity obstruction.** With toy day coordinates S=0,F=31,H=1 and daily anchors0…30, complete mature past1d is possible at30 anchors,7d at24,30d at exactly one: t=30. That is31October00 UTC, whose24h target ends at1November00. There is a valid boundary instant, not a positive-duration training range. The two-anchor admission gate therefore excludes30d even before source aggregation; actual training calendars can only narrow this availability. Its one-anchor computability does not establish support for choosing or training a30d policy. No history is borrowed from another month and no current reservation is opened.

**testable_prediction.** The fixed rate-agreement gate might choose short history during a user activity change and longer history when frequencies agree, producing a useful compact input for the fixed learner. It can instead react to logging duplicates, misread seasonal behavior, or discard useful short-term detail. Low support returns the shortest scale, which can itself be noisier. No claim of unbiased rates, optimal bandwidth or better quality follows from the gate.

**Simplest strong fixed-window control.** Use W plus fixed1d pair rate/count, the **same h selector output**, and the same common full7d missingness. Existing B/W already supplies pair-view7d. Thus this control contains both1d and7d pair information and the gate; it can reconstruct the treatment. This controls for the extra user-history signal in h and avoids comparing against a deliberately weaker redundant7d-only column. If exact current-W alias review finds the short pair parent already present, treat it accordingly; do not manufacture a novelty claim or pad unused columns. Different actual closures require a prospective matched design before fitting.

This reconstruction claim concerns the admitted October ladder{1,7}. A longer-corpus30d extension needs a matched fixed30d parent and a new closure/cost design. The proposal is a representation test, not discovery of new information. In stable h=7 cases, treatment rate is merely an affine transform of the existing pair7d count. A generalization claim about *window selection* would require more than one frozen heuristic realization. Any future tuning of6,1/3, ladder widths or the admission threshold consumes additional source work, fits and feedback looks; it is not included here.

**nearest_source_free_experiment / cheapest falsifier.** Compile the calendar gate and exact integer selector without a DB. Test raw lower/upper boundaries, duplicate multiplicity, global-peer permutation, future suffix, zero versus incomplete coverage, source gaps, negative/invalid annulus counts and checked arithmetic. Compare directly computed window/band counts with required parents, record which were demanded, and enforce that an excluded30d leaf is never read. Then show that the matched fixed basis reconstructs the adaptive scalar and construct two histories it distinguishes while the adaptive scalar loses detail. The literal checks below cover arithmetic/selected boundary cases; no production compiler, lazy source executor or model is claimed.

**task1benefit.** A typed operator can make scale selection and its availability/cost explicit, rather than hiding window choice inside a bespoke block or a decay fit. Static coverage/maturity admission can prevent spending on an unsupported scale. A useful result would be exact, reproducible automatic calculation and possibly a measured representation benefit against the fixed basis; not a universal window optimizer.
