# Wave059 C — bounded history-statistic bank

Audit: REES46 supplies irregular sparse events, not sampled sensor states. Represent each repeated (user,item,T) separately: 168 UTC-hourly raw-view multiplicities on [T−168h,T), excluding all timestamp-T peers. Zero means no observed row under complete source coverage; truncated/unknown history remains missing, distinct from young observed users. Keep mature 24h labels, complete fixed Q/C, off-C full Y and zero-Y queries. Any learned imputer/filter must fit train only; this bank itself is stateless.

Mechanism: a tsfresh-derived bank emits six predetermined statistics: number_peaks(n=1,2), longest_strike_above/below_mean, autocorrelation(lag=1,2). Units are bins/peak counts/dimensionless correlation. This adds time-order mappings beyond ActionVector/Breadth/CartTiming; it automates calculation, not schema inference or unrestricted generation. [Versioned calculators](https://raw.githubusercontent.com/blue-yonder/tsfresh/v0.21.2/tsfresh/feature_extraction/feature_calculators.py). Charge all undefined-correlation and coverage masks; deduplicate against every physical B/support/retrieval column before allocation. Benefit: a reusable bounded bank can distinguish persistent activity from isolated bursts without searching more window widths. Counter: sparsity, bin phase and ordinary subwindow contrasts already explain everything.

Prediction/falsifier: append (1,0,1,1,0,1) versus (1,1,1,0,0,1) after 162 common zero bins. Totals, first/last activity and 24h/168h counts match; above-mean runs should differ (2/3). A future invented canary also covers boundary seconds, peers, all-zero/constant vectors, unknown coverage and repeated anchors. Failure rejects semantics, not ranking utility. UNRUN.

Default supervised FRESH is rejected for direct transfer: its [paper](https://arxiv.org/html/1610.07717v3) and [v0.21.2 filter](https://raw.githubusercontent.com/blue-yonder/tsfresh/v0.21.2/tsfresh/feature_selection/relevance.py) do not make correlated candidate rows/users IID; BY addresses feature-hypothesis dependence. Any future grouped selector needs mature train-only feedback and explicit query weighting. Reused 73-positive-Q selection is adaptive; classification benchmarks establish neither ranking gain nor local cost.

Decision: merge as optional TLAB-014/016 refinement, with TLAB-013 binning sensitivity; FB-05 already covers temporal roughness. No novelty/ID claim. Future bounded comparison: B, B+bank, B+matched physical-column manual contrasts, identical Q/C/Y and predeclared learner/prefix. Reject utility without gain over both controls under the frozen Recall rule; retain only exploratory promise if successful. Record extraction, failures, fits and validation looks; local cost is unknown. All experiments deferred/UNRUN; no grants/gates.
