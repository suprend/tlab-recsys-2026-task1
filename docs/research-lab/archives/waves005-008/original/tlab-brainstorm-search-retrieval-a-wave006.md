## Cheapest falsifiers: what a search win could actually mean

**Compressed syntax changes reachability.** Let `M(x,y)=(x+y)*(x+y)*(x+y)`. Expanded binary AST size is 11 nodes: 6 leaves; 3 additions, 2 multiplications. A one-token macro can pass a compressed depth/size cap that rejects the equivalent primitive tree. Any resulting discovery advantage may be budget bookkeeping. Under a shared 7-expanded-node cap the macro must also be rejected. More output programs, shorter tokens and renamed blocks are not evidence of a better utility search. FA04 already identifies this risk; this witness makes the rejection executable in a later literal gate.

**Sample equality is not semantic equality.** `f=a/(1+b)` and `g=a/(1+b+c)` coincide in a sample where c is always 0; at a=2,b=1,c=2 their values are 1 and 1/2. These expressions illustrate a counterexample, not proposed new features or admitted operators. A value cache keyed by sample equality could remove a genuinely distinct program and falsely make later search look efficient. Conversely, `x+x` and `2*x` are the same ordinary arithmetic function but can carry different NULL behavior if an implementation invents protected operators. Dedup uses proved, versioned semantic rules plus dependency identity, never empirical equality alone.

**Feedback costs do not disappear under another name.** A “proxy” obtained by refitting a ranker consumes a fit. A precomputed archive containing those scores has inherited labels and construction costs. UCB over a manually listed inventory can allocate evaluations automatically, but it has not learned new operations or grammar. A grammar generator with fixed proposal probabilities produces new syntax mechanically, but it has not learned a useful proposal policy. Neither fact invalidates the method; each limits the supported claim.

## Finite literal recipe before any real-source proposal

Use a deliberately small generic grammar, not 202 hand-written blocks. Terminals x,y are nullable dimensionless scalars; productions are binary Add and Mul with ordinary strict NULL propagation. Maximum depth 2 gives raw syntactic counts `N0=2`, `N1=2+2*2²=10`, `N2=2+2*10²=202`, expanded size ≤ 7. This is a mechanics DSL, not an extension approved for the existing compiler or a claim that arbitrary shares are useful.

Audit all 202 ASTs on 36 rational assignments from `{NULL,0,1/4,1/2,3/4,1}²`. Upper bound:202×36×7=50,904 primitive evaluations; state ≤ 202 ASTs/polynomial forms and7,272 scalar results, zero model fits. Polynomial canonical form plus required NULL-dependency set can prove aliases within this restricted Add/Mul language; those rules do not automatically extend to division, clipping, temporal aggregation or protected arithmetic. Literal outputs verify semantics, not recommender quality.

Before generating an archive, hold out the semantic family containing `(x+y)²`, including all aliases. Keep the primitive grammar unchanged and freeze ≤ 8 archive programs. Compare archive-prior/macro proposals with primitive proposals for a predeclared artificial utility oracle on the same 202-function envelope. Charge generation, rejected/duplicate candidates and archive creation; count total attempts, expanded-node work and distinct canonical programs. No “retry until enough successful proposals.” Removing only a spelling from the archive would leak an equivalent held-out program. This checks whether a proposed search can move beyond its archive; it does not establish useful real-data extrapolation.

Then give two acquisition policies **the same complete candidate-identity bank and initial feedback**, allowing different visited subsets. No later score observed by one policy is silently revealed to the other. Discovery and acquisition results must be reported separately. A fixed manual macro control may be chosen before the artificial oracle is revealed; its preparation time and access are logged. This remains a conditional comparison against that declared inventory, not the unknowable best human program.

Negative literal outcome is informative: no beyond-archive discovery, all gain attributable to unequal expanded caps, aliases removed only by sample values, or identical choices under equal feedback means this gate does not justify adaptive search.
