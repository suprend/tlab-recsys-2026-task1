## Primary grounding and negative transfer boundaries

[Mell, Zdancewic and Bastani, POPL2024](https://www.cis.upenn.edu/~stevez/papers/MZB24.pdf) synthesize programs using abstract interpretations that bound a specified quantitative objective over input-output examples. The inspected author PDF is a November2023 draft; the [author publication page](https://mell.ac/) and [artifact](https://github.com/stephenmell/popl2024-artifact) identify the POPL2024 publication. A newly indexed2026 arXiv entry must not be counted as an independently new mechanism. The guarantee concerns the stated objective/examples and sound abstract transformers; it does not bound downstream CatBoost NDCG from an AST's type. The artifact explicitly asks a new language implementer to supply concrete/abstract semantics and a search graph. Its documented Quivr objective uses labels and tensor utilities. We have supplied none of those for recommendation utility and installed nothing.

[Bee Search](https://webdocs.cs.ualberta.ca/~santanad/papers/2023/ameenL23.pdf) is a foundational2023 best-first bottom-up method; its [AAAI2024 entry](https://ojs.aaai.org/index.php/AAAI/article/view/30591) is an abstract reprint, not another new study. Its [author starter repository](https://github.com/lelis-research/BeeSearch) explicitly says this sample was not the paper's experimental implementation. Inspected [bee.py](https://raw.githubusercontent.com/lelis-research/BeeSearch/main/src/bee.py) uses type-indexed queues, but also a pretrained Bustle model, program evaluation on examples, and output-tuple deduplication. `has_equivalent` returns true when an example result is None. These are important transplantation limits: no pretrained guidance, example agreement or rejection of legitimate NULL-valued programs is imported into our zero-fit proposer.

## A006-01 — lazy typed enumeration with sound partial closure pruning

**mechanism.** Replace bundle recipes with a finite operator catalog and inference rules: GroupCount, GroupDistinct, ObservedRecency, SafeSubsetShare, and an EmitSet root. Actions, key bindings and windows come from declared schema/capabilities, not separate handwritten blocks. Start with windows24/168h and current supported grains/projections; do not invent arithmetic, nested retrieval, new windows or unavailable metadata. A human still defines the catalog and semantic adapter. The automation claim is deriving compositions/bundles from those rules, not discovering semantics from field names.

Enumerate by primitive-node count and a fixed structural tie order. Index partial terms by required result type and unresolved obligations. An abstract state records possible grain/free variables, units, temporal policies, nullability and physical output dependencies. Discard a partial term only if no allowed completion can satisfy typing, or a sound lower bound on **unavoidable new physical columns** exceeds the frozen candidate cap. An uncertain bound stays permissive. Complete terms pass the same exact compiler/alias/closure checks as the control. Output the next legal canonical EmitSet with exactly three new physical columns, including supports/masks/coverage; report exhaustion if none appears. Whole candidate slots and symbolic expansion attempts have separate counters. Invalid/collision attempts do not create extra materialized/model slots.

For a partial program p, the ideal bound is `MustNew(p)=intersection{NewCols(c): c completes p}` after the fixed emitter's canonicalization. The implementation need only compute a conservative subset. Summing child closure sizes is generally unsound because dependencies can overlap; counting the union of every possible hole output is also not a lower bound. Committed output leaves may not be cancelled by later rewrites under this grammar. If a future grammar permits cancellation, that assumption must be removed and its transformer re-proved. The bound concerns columns, not runtime, source cardinality or usefulness.

**Exact semantic typing.** Every binding includes source/protocol version, grain/nominal keys, free variables `{u,i,t}`, action, raw bag versus exact distinct, projected key, window/endpoints, availability, unit and metadata/NULL policy. SafeSubsetShare requires same action/window and a proved population subset; cart/view is not a probability simply because both are counts. Observed recency uses the full prefix. Category counters use historical event category; candidate conditional keys use the complete latest global timestamp bucket. Unknown category gives NULL, known empty count0, zero denominator NULL. Global peers are excluded; future suffix cannot change the past definition. Output identity includes full B/W and retrieval aliases. Same values on tiny fixtures are not a proof of an alias.

The emitter is part of typing. A semantically redundant category mask remains a new physical column if the emitter gives it a separate name. Existing005 does this in cases documented by round026. Reusing B's mask therefore requires a separately reviewed lowering policy; the search cannot silently assume it. No change to the frozen emitter follows from this draft.

**testable_prediction.** Where many partial branches necessarily violate unit/availability/closure constraints, sound early pruning should examine fewer completed terms before emitting the same ordered legal prefix as a plain enumerator. Where most terms are already legal or bounds are weak, bookkeeping may be slower. This predicts enumeration efficiency and preservation of a declared structural order, not quality, actual source speed or general optimality under a timeout.

**Matched simplest control.** Size-first typed enumeration with checks at completed terms, using the exact same catalog, finite depth/node limits, canonicalization, emitter, tie order and output quota. The treatment changes only when obligations/closure rejection happen. It must produce the same legal prefix whenever both finish that prefix; otherwise a soundness/order defect or changed prior has occurred. Comparing treatment with an untyped generator exaggerates the benefit. Uniform sampling over the same legal canonical completed programs is the simplest future quality-search control; it does not receive weaker typing or missingness checks. A future outcome-aware selector would need its own mature training-only feedback, fit/look ledger and fresh reservation.

**nearest_source_free_experiment.** Use a tiny finite grammar with≤8 leaves,≤5 constructors and≤7 nodes. Exhaustively enumerate a small depth-two sublanguage to establish a reference legal set/order. Compare final-check and early-pruning implementations, then deliberately inject wrong bounds. Include shared dependencies, separate physical mask names, unknown/zero denominators, window separators, repeated raw events, same-second NULL metadata and current-B aliases. Check the prefix, not just the number of outputs; log every attempted expansion, rejected branch and exact rejection reason. No source data, SQL, model or external API is needed. This draft executes only the literals below; no enumerator implementation is claimed.

**benefit_task1.** The next operation/composition can be selected by executable type and closure rules with a visible structural prior, avoiding a manually authored recipe for every bundle. If verified, this strengthens bounded automatic generation and makes its cost/failure attribution reviewable. It cannot establish that size-first features are useful or that an intelligent selector beats random search.
