## TB1 / V7-R1 — common-mode fault calibration with anchored witness receipts

**Mechanism.** Retain the existing gold bank and independent interpreter. For each applicable semantic fault, generate three placements: producer only, oracle only and both. Separate implementation syntax is insufficient: independently written loops can share the same mistaken cutoff or business assumption. A comparison gate receives the same fixed raw bag/Q/C/context and must distinguish pairwise agreement from agreement with the externally frozen contract. Its evidence records the fault, precondition, complete output closure, expected literal, actual discrepancy and which stage rejected it. Rejection only because a hash is stale does not establish a semantic check; tiny synthetic identities can be mechanically resealed before the semantic seam.

Any automatically found witness receives a typed receipt: original AST/compiled-fragment identity, independent denotation version, schema constraints, explicit source/anchor/window/NULL/duplicate policy, reached row/value bounds, witness rows and expected typed keyed outputs. Validate constraints and raw-model→serialized-row round-trip before treating the witness as real. Preserve statuses `refuted-with-valid-witness`, `bounded-pass`, `unsupported`, `unknown/timeout` and `invalid-witness`. Never count an equivalent or merely unwitnessed mutant as killed. This is an engineering refinement, not a new theorem or elimination of the oracle problem.

**Prediction.** Unilateral mutation sensitivity can be100% while the same gate accepts all jointly corrupted pairs. The unchanged literal bank should catch those common-mode faults when it contains their distinguishing examples. The proposed evidence structure may reveal gaps for new AST semantics or witness export; it need not improve detection beyond the existing bank. The main alternative explanation is intentional tailoring of injected faults to the gold examples: success then measures only named-fault sensitivity, not independent-oracle reliability or unknown-bug detection probability.
