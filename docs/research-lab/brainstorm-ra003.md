## RA3-01 — redundant-audience penalty, not user activity alone

**Primary source versus adaptation.** The September 2026 [Efficient Swing Computation technical report](https://arxiv.org/html/2609.16850v1) presents ASC/K-ASC computation algorithms, while explicitly attributing Swing to Yang 2020. The [author repository](https://github.com/HKBU-LAGAS/K-ASC) links that preprint; its README advertises SIGMOD 2027 and gcc 8.5. Treat this as a 2026 preprint, not an already completed 2027 publication. README/code directory availability was verified; implementation files could not be retrieved through the source reader, so executable correspondence is unverified. Paper Algorithm 1 enumerates distinct ordered user pairs, intersects their item sets and adds inverse-overlap weights. Its approximation guarantees concern Swing scores, not future purchase recall. Full exact discovery is quadratic in seed audience; small returned K does not bound discovery. [Paper §§1–3](https://arxiv.org/html/2609.16850v1).

Own inexpensive version uses binary past view edges and unordered pairs:

`s(q,j) = Σ_{u<v in U(q)∩U(j)} 1 / (1 + |I(u)∩I(v)|)`.

This is half the ordered score, preserving rankings. Query-user removal happens before counts, gates and scoring. Denominators include q and j. All source arms require at least three co-users. Remove source anchor items from source output, with identical control filtering; bought items remain in final C. For each of at most four shared anchors, discover all eligible endpoints exactly, retain top 100, sum across anchors, return top 20. Stable productID resolves ties. No basket/order interpretation is required: shared users can have viewed the items days apart.

**Literal non-alias/falsifier.** Six background users: three have `{q,a,z}`; the other three have `{q,b,w1}`, `{q,b,w2}`, `{q,b,w3}`. Every user degree is3, both candidates have degree 3, q degree 6 and both co-counts 3. Their ordinary and activity-weighted cosine, shrinkage, Jaccard and lift are equal. Yet unordered Swing gives a=`3/(1+3)=3/4`, b=`3/(1+2)=1`. With a<b by ID, tied ItemCF top 1 selects a; Swing selects b. This was checked using exact rational arithmetic. Cheapest source-only rejection: a proposed implementation returns equal scores, includes diagonal user pairs, omits denominator items, or attributes the reversal to larger support. Do not replace this fixture with an ItemCF-versus-Swing comparison on unequal degrees.

**Matched control and counterhypothesis.** Mandatory denominator-ablation control replaces every pair weight with 1, giving `s0(q,j)=choose(co_users(q,j),2)`; this isolates redundancy from Swing's superlinear support effect. Also compare the frozen activity-weighted ItemCF formula. All three arms share the graph, gates, anchors, three-co-user floor, top 100 per anchor and top 20 final source. A cohort can share legitimate tastes or campaigns; discounting it can remove the strongest purchase signal. This is neither bot detection nor causal evidence of independent demand. Three co-users generate only three pairs; the narrow gate can leave few supported anchors. Report unsupported-seed and zero-source rates on every common query, not only supported queries.

**Exact finite discovery.** Under the shared bank limits below, admit whole background users only if their full-window view degree ≤ 32; do not clip their histories. All arms additionally accept an anchor only if its audience after query-user exclusion ≤ 32. Larger audiences return no source from that anchor, with no truncation/refill. Each anchor has ≤ 496 unordered pairs, each sorted merge ≤ 64 comparisons and ≤ 32 score updates. Four anchors use ≤ 126,976 merge comparisons plus ≤ 63,488 Swing updates, and ≤ 4,096 profile-edge visits for co-counts; distinct discovered IDs ≤ 4×32×32=4,096. Three arms conservatively charge three such passes even if shared work can later be proved. These are primitive-operation bounds, not wall-time promises. Avoid full-catalog K-ASC preprocessing or an all-item-pairs score bank. Reject the pilot if the degree gate suppresses most queries or if the bounded source cannot be built completely; a partial graph does not establish affordable retrieval.

## RA3-02 — immediate-reversal exclusion at the same path length

**Primary source versus adaptation.** [Non-backtracking Graph Neural Networks](https://seonghyun26.github.io/hyun/assets/publications/24TMLR_NBA-GNN.pdf), TMLR September 2024, has a 2023 preprint predecessor. Its Eq 3 excludes the prior node in edge-message updates. The [author-linked code](https://github.com/seonghyun26/nba-gnn) is a neural graph/node benchmark implementation; inspected module code contains learned transformations, not a ready-made recommender. The paper also permits “begrudging” reversal at degree-one nodes. Own proposal borrows only the topology restriction and uses strict dead-end termination; the paper's tree access-time result for the repaired walk must not be claimed for this kernel. No recommendation gain transfers from its classification benchmarks. [Paper §§3.1–3.2](https://seonghyun26.github.io/hyun/assets/publications/24TMLR_NBA-GNN.pdf).

From each shared anchor sample a four-edge walk item→user→item→user→item on binary past views. At every hop choose uniformly among neighbors except the immediately previous node and the query user. Terminate if none remain; terminal-at-hop 4 endpoint counts divided by attempted walks are scores. This forbids `x→y→x`, not all revisits: a four-cycle may return to its start. Exclude anchor endpoints in both arms. No recency weights, restart, unbounded retry, cooldown, confidence threshold, or extra walk-length choice is introduced.

**Literal non-alias/falsifier.** Chain `a—u1—b—u2—c`, start a. A conventional four-step walk yields endpoint masses `(a,b,c)=(3/8,1/2,1/8)`; strict nonbacktracking yields c with probability 1. After the identical anchor exclusion, top 1 changes b→c. Exact rational enumeration verified this. Length, seed and graph are unchanged, so walk4-versus-walk2 does not explain the change. Counterfixture `a—u1—b`: strict four-step walks die at b; the ordinary walk retains endpoints. Cheapest rejection: the implementation silently reverses/restarts at that dead end or counts only successful attempts, hiding lost mass. A repaired degree-one kernel would require a separately frozen variant, not a post-failure rescue.

**Matched control and cost.** Use ordinary four-step walks with exactly the same anchors and 1,024 attempted walks per anchor, ≤ 4,096 per query; both arms use one fixed preregistered RNG seed. Unequal numbers of successful walks are part of the result, not justification for extra calls. At most 16,384 transitions per arm/query, endpoint map ≤ 4,096 entries and a top 20 heap. Source calls ≤ 4 per arm. Sampling must skip excluded neighbor positions directly in sorted adjacency; no rejection loop. Query-user position lookup is paid, ≤ 19 comparisons with ≤ 320,000 admitted edges; previous-edge positions can be carried. No Hashimoto/line-graph matrix is materialized. Report dead-walk fraction, source diversity, overlap with the ordinary walk, and stochastic uncertainty; sampled zero is not proof of an absent path.

Counterhypothesis: useful intent is local, and repeated edge traffic reinforces real affinity; forcing travel outward can favor weak bridges, noisy one-off viewers or stale inventory. No impressions or stock field distinguishes availability from preference. This refinement is cheaper than a learned retriever only after its adjacency bank has been honestly paid for.
