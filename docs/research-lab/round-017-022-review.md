**CPU ledger — конкретизация, не возражение.** [Python resource](https://docs.python.org/3/library/resource.html#resource.RUSAGE_SELF) относит SELF ко всем threads текущего процесса, CHILDREN — к terminated/waited-for children. Для implementation следует явно выбрать непересекающиеся buckets: parent SELF плюс CHILDREN increment, **либо** parent SELF плюс собственные worker measurements с оговорёнными tails. Сложить одновременно CHILDREN и те же worker SELF — двойной счёт. Parent SELF сам по себе детей не включает; запрещать его сложение с CHILDREN вообще было бы ошибкой.020 этого буквально не утверждает, но короткую формулировку полезно уточнить. Wall×threads не measurement; missing historical008 CPU остаётся unknown, а не0/остатком бюджета. RSS peak также не складывается как CPU-seconds.
