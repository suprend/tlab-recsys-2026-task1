A допустим только как последующее описание. AP-term на фактическом ранге r = hit(r)×precision(r)/min(12,|fullY|), Recall-term = hit(r)/|fullY|. Prefix общий для всех bins, исходные позиции и все Q+ с нулевыми вкладами сохраняются. Компоненты должны восстановить показатели каждого пользователя/модели и парные разницы. Средние страт Y восстанавливают macro только с весами по числу пользователей. Будущий размер Y не входит в features/selection. Bins заданы после наблюдения результата; это exploratory bookkeeping, не причинная атрибуция. Можно отложить без потери полноты core.

B2 используется без слов «выиграл»/«эквивалентен» по одним point estimates: интервалы условны на моделях и неделе, пересечение нуля означает неопределённость. M+all−M описывает конкретный pool; selected−M — всю процедуру; selected−каждый random/среднее трёх — эти зафиксированные draws. Random mean — среднее AP на пользователя, не score ensemble и не универсальная оценка selector. Ни один development исход не меняет финальные arms M/selected, параметры, seeds или training policy.

Core priority: завершить шесть recipes → независимый metric audit → заморозить M прежним правилом → prepare pool/random names → M+all и training-only PVC top12 → selected/random controls → diagnostic confirmation → неизменённый final/report. Новых обязательных ветвей нет.
