## TB-B001 — synthesize an AST-specific distinguishing test portfolio

**Primary mechanism.** GenMorph (TSE2024) searches executable metamorphic relations using false-alarm and missed-mutant objectives, favoring small relations, then filters on fresh inputs. It learns from implementation behavior, so a generated relation is not a specification proof. The [author paper](https://valerio-terragni.github.io/assets/pdf/ayerdi-tse-2024.pdf), [publication record](https://valerio-terragni.github.io/publications/) and [author repository](https://github.com/jonayerdi/genmorph) support this mechanism and date.

**Proposed operator.** Compile each typed feature AST into a response grammar, then search small event edits and select a minimal distinguishing portfolio. For raw count, duplicating an eligible event changes the value by one. For distinct, it changes by zero or one according to existing membership. For a share n/d, duplicating a numerator event changes both supports; adding an outside-subset event changes only d. Score a candidate relation by zero false alarms on independent literal semantics, new mutant phenotypes killed, and total comparisons. Shrink witnesses while preserving the specific distinction. Search on the independent semantics, not production output presented as truth.

**Novelty delta.** Rounds018/045 already propose bounded generation, shrinking and hand-specified laws. This candidate earns a new mechanism only if automatic AST-to-relation synthesis plus portfolio selection finds a distinct failure missed by their fixed bank at the same evaluation count. Merely running that bank more often is a duplicate. It generates program-specific evidence when a new operator is proposed; it does not add more generic checklist items.

**Inputs/clock and falsifier.** Synthetic events, explicit T/source coverage/category context, fixed Q/C and ASTs; no labels. Literal: n=1,d=2 gives1/2; duplicate numerator gives2/3; add denominator-only row gives1/3. A relation asserting share invariance under either edit must be rejected. The cheapest adversary is a candidate-only denominator mutant: include one off-C category event and require the synthesized witness to separate it. Counterhypothesis: synthesis merely recovers existing laws or overfits the same mutant family.

**Fair control/cost/claim.** Compare fixed018/045 portfolio and random portfolio under identical comparison ceilings and fresh, independently authored mutants. Proposed future ceiling:4 ASTs×9 implementations including original×64 bags≤12 events=2,304 interpreter evaluations,60 CPU seconds/256MiB,0 fits; construction, shrinking and failures included. If capped, publish incomplete coverage. Possible claim: improved bounded test synthesis efficiency on named operators/mutants; no universal correctness, predictive usefulness or production speed claim.

## TB-B002 — context-conditioned feature gates that can abstain locally

**Primary mechanism.** [c-STG, ICML2024](https://proceedings.mlr.press/v235/sristi24a.html) models feature inclusion as conditional Bernoulli gates whose parameters come from a context hypernetwork, jointly trained with a predictor and sparsity penalty. The [paper §3/§4](https://arxiv.org/html/2312.14254v2) compares population-level selectors and dense prediction with context also supplied; [author code](https://github.com/Mishne-Lab/Conditional-STG) is available.

**Proposed operator.** Learn π_j(z) over a small, declared feature family, with z limited to pre-T history coverage/support, category-known state and source-level behavior capabilities. A feature can be useful with complete history but unhelpful under short observation; one global selection discards that distinction. Structural invalidity is rejected before learning: unsupported cart is never silently encoded as cart-count zero. At inference, emit the deterministic frozen gate plus its validity/missing companions. Do not infer gate state from Y, future activity, current score errors or unseen-source outcomes.

**Novelty delta.** Existing capability adapters decide whether arithmetic is meaningful. This gate decides whether a supported feature should influence prediction in a particular observation context. It is neither another availability mask nor global temporal invariance. External metadata can establish whether z/f exist; it cannot train or validate a transferred gate.

**Cheapest literal falsifier/counterhypothesis.** Let z,x1,x2 be balanced bits and y=x1 when z=0, otherwise x2. A single feature predicts75%, whereas contextual choice predicts100%. But a dense tree supplied x1,x2,z also represents100%: this literal probe falsifies any claim of additional information or uniquely greater expressivity. The real hypothesis is better sparsity/robustness at a finite budget. Strong counter: tuned boosting already learns the interaction; gating adds variance or hides rare valid signals.

**Fair control/cost/claim.** A future comparison needs four fixed fits: strong boosting with all f,z; dense neural predictor with f,z; the same predictor with global stochastic gates; c-STG. Fix neural width/epochs, record hypernetwork parameters, and avoid architecture tuning. Use≤2,000 predeclared Q per split,≤220 C/Q,≤4,096 gate parameters,4 fits/4 development looks and60 CPU minutes total including source, gate learning, failures and inference; stop if insufficient. All histories and learned gates precede a newly reserved development cutoff. Possible claim: context-dependent sparsification improves predictive robustness versus these controls under declared observation regimes; not universal dataset transfer or causal feature relevance.

## TB-B003 — compare marginal usefulness on common context mass

**Primary mechanism.** [WRI, TMLR2024, §3](https://arxiv.org/html/2407.18428v1) matches risks after weights satisfy α(z)p1(z)=β(z)p2(z); cross-density weights α=p2,β=p1 avoid requiring equal unweighted risks. Its guarantees depend on invariant-feature and general-position assumptions. [Author repository](https://github.com/ginawong/weighted_risk_invariance) supplies the original implementation. Our criterion below is an adaptation, not a WRI theorem for ranking.

**Proposed decision.** Predeclare≤8 discrete, pre-T observation contexts z. For two environments and a fixed B/B+f pair, estimate δ_e(z)=E[NDCG(B+f)−NDCG(B)|z]. Compare both benefits under normalized common mass q(z)∝p1(z)p2(z). Require positive common-mass benefit in each environment, bounded difference, and adequate overlap/support; otherwise abstain. Thresholds are frozen before new outcomes. Query-level1−NDCG is merely a bounded predictive loss here; fullY denominators and fixed candidate support persist.

**Novelty delta.** Equal raw gains or equal feature distributions are unnecessary. This operator separates changed context proportions from changed conditional usefulness, without pretending that observed z is a causally invariant representation. It can identify where a transferable usefulness claim has no empirical support.

**Literal falsifier.** Take p1=(.9,.1),p2=(.1,.9),δ1=δ2=(.2,.05). Raw gains are.185/.065; normalized common-mass gains are.125/.125. A procedure rejecting solely because raw gains differ fails. With δ=(.1,−.1), both common gains are0: stability alone must not promote f. With disjoint supports, return unknown, never zero-risk success. Counterhypothesis: coarse contexts hide changing conditional relationships; small overlap makes estimates unstable.

**Fair control/cost/claim.** Compare pooled-gain and unweighted environment-stability selectors using the identical predeclared B/B+f artifacts, outcomes and looks. Future ceiling: two environments×2,000 Q,≤8 bins, minimum20 Q/bin/environment, overlap coefficient Σmin(p1,p2)≥.2, one pass over≤880,000 saved score rows,60 CPU seconds post-score. The cross-density normalizer Σp1p2 is separate from this overlap coefficient. These are proposed operating rules, not statistical guarantees. The two underlying model fits/source costs need a separate inclusive≤60 CPU-minute pilot; saved predictions are not free or current artifacts to reopen. Possible claim: common-support predictive gain stability for specified contexts/dates. No guarantee on disjoint populations or changed observation mechanisms.

## TB-B004 — select by an action-specific reversal radius

**Primary mechanism.** [Pereira/Said/Santos, RecSys2025](https://arxiv.org/pdf/2508.05398), §3–§5, separates logging distortion from evaluation sampling and studies resolution, fidelity, robustness and ground-truth agreement using fully observed preferences. [Author repository](https://github.com/LatinUFMG/recommenders-sampling) is linked in the paper. REES46 cannot reproduce their ground-truth/exposure comparison.

**Proposed decision.** For a future fixed B/B+f pair, report the smallest tested distortion budget at which paired gain changes sign, as a grid bracket rather than the true minimal perturbation. Maintain separate radii for view-history thinning, cart-history thinning, and candidate subsampling. Histories change only beforeT; sampling uses pinned, outcome-blind hashes. Observation arms retain Q/C/fullY; sampling arms retain Q/fullY and use the same reduced C for both models. Never retain positives deliberately or insert out-C targets. Partial observation remains annotated, and scores are recomputed without retraining. Select only if the predeclared robustness requirement survives; a large clean gain cannot conceal a small tested reversal.

**Novelty delta.** HYP013 already allows protocol sensitivity. The proposed new operator uses least-distortion sign reversal as an automation admission criterion, identifies its responsible behavior channel, and keeps sampling separate. If only descriptive sensitivity plots result, merge into013 instead of claiming novelty.

**Literal falsifier/counterhypothesis.** At K=1, three queries give f two wins and B one win. A fixed deletion removes the distracting candidate in each f-winning query; both now hit there, while B retains its third-query win. Gain changes+1/3→−1/3 after2/6 candidate deletions. Define deletion by item IDs before assigning toy labels; no positive-aware sampler. This disproves monotone preservation of model order under candidate reduction. Conversely, arbitrary thinning may be unlike real logging drift, so a small radius need not predict future failure.

**Fair control/cost/claim.** Compare clean-gain selection with the radius rule on identical future models and one locked grid: baseline;10%/25% view thinning;10%/25% cart thinning;20%/50% C removal.≤2,000 Q,220 C/Q, two models, seven cases/seven paired development looks:≤6.16 million score-row evaluations,0 refits and60 CPU minutes inclusive of source recomputation/inference/evaluation/failures. This is an alternative prospective pilot, not a current grant. Possible claim: robustness to these synthetic observation/sampling domains. No preference recovery, exposure correction, general logging robustness or causal lift.
