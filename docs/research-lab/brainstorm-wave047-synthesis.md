Оба автора предлагают RetailRocket сначала только для event-only count/distinct/recency. `visitorid` остаётся наблюдаемым actor: равенство аккаунту или искусственной сессии не установлено. Sessionization может изменить eligibility и потерять будущую покупку; future/latest property join может внести будущую категорию. Нельзя автоматически переносить весь B41/W44, price/brand/category-code или pruning по stock.

Предложенные literal canary и dataset pilot остаются UNRUN; малое число Q не ограничивает полную стоимость scans/state/authentication.

Сведения о version/license/counts относятся к publisher-indexed card text. Direct opens дали ноль разобранных строк; immutable release, доступность скачивания, единицы времени и arrival/property clocks не проверены. Это условный перенос расчёта, не predictive transfer и не качество рекомендаций. [Принятый018 scope](../backlog-reviews/public018-complete-output-acceptance.md) не расширяется.
