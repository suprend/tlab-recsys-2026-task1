## Primary mechanism and provenance

[Zhang and Toumani, TODS 49(2), article 7, 10 April 2024](https://doi.org/10.1145/3649133), “Sharing Queries with Nonequivalent User-defined Aggregate Functions,” exposes aggregation semantics as canonical partial states. Sharing is justified when a computable scalar function derives the requested state from a stored state for every admitted input multiset. SUDAF restricts its expression language because unrestricted sharing is undecidable. Section 6 extends state reuse to query rewrites using partial-aggregate views; different aggregate functions can share verified intermediate states. This is aggregation-expression derivation, beyond reusing an identical groupby or temporal pane. It is not an exact sliding-expiry algorithm or a universal cost-optimal operator scheduler. Its primitives include summation/product and composed scalar operations; exact distinct is not established. A practical transfer should whitelist proved derivations and charge planning/materialization costs, rather than implement arbitrary symbolic equivalence. These statements were inspected in the publisher’s primary search rendering; direct ACM open returned 403. [Primary article](https://doi.org/10.1145/3649133).

## Exact typed adaptation: reviewer proposal, not paper guarantee

A shared node must include grouping key, predicate, raw-row multiplicity, NULL admission, exact interval/cutoff, dtype, and arithmetic semantics. For one identical non-NULL bag, `(n, sum(x), sum(x²))` derives mean and population variance. Keep raw count separately. Empty/all-NULL mean and variance return NULL under the chosen contract. Do not convert NULL to 0 or deduplicate repeated events.

All rows at a global timestamp form one peer block: answer every anchor at`t` before inserting any row timestamped`t`. Windows are `[t−W,t)`; expire rows strictly below`t−W`. Sharing a final long-window state does not reconstruct a shorter window automatically. Expiry requires retained event contributions or equivalent exact indexed boundaries. Arbitrary late arrivals require an explicit completeness/watermark contract.

Exact distinct needs keyed occurrence counts plus expiry witnesses; two panes containing the same ID cannot add their distinct counts. Bags`(0,0,3,3)` and`(0,1,1,4)` both have`n=4,sum=6,sumSquares=18`, while distinct counts are 2 and 3. Thus moments cannot derive distinct. State grows with active distinct IDs/events; no constant-memory exact-distinct claim. Rational equivalence also does not establish bitwise equality after floating-point reassociation.
