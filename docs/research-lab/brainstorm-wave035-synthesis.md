# Волна035: общая подготовка B41

Два независимых FIRST и отдельный скептик приняты Root как одно уточнение HYP046/round073/wave031. Публичный путь уже разделяет вычисление source-признаков; возможная будущая экономия относится только к повторной подготовке неизменного B41 host transport. Новых механизмов, ID, задач и grants нет.

Механизм — аутентифицированное общее представление B41 без повторного использования model/Pool state. Проверяемое предсказание: реально избегаемая подготовка должна превышать build, hash, read, projection/copy и lifetime costs. Ближайший тест — prospective invented AB/BA canary, до16 calls и двух полных train+selection cache builds; он UNRUN/ungranted. Польза для Task1 — возможное сокращение инженерной стоимости при сохранении точных feature/fullY/feedback contracts.

Контроль — текущий shared-source плюс последовательный loader. Все per-use pins, ключи, порядок, NaN, weights, fullY и доступность сохраняются. Число1,944,800,000B — арифметический numeric payload, не RSS/capacity; Amdahl и число builds условны, фактическое ускорение не измерено.
