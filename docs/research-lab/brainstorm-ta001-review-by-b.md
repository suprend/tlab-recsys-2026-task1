## Actionable findings

1. **[P2] Merge TA-01 into FA04 instead of counting a new mechanism** — [report line13](brainstorm-ta001.md#L13). Published [FA04](brainstorm-fa001.md#L49) already learns typed abstractions from a frozen archive, expands calls into audited primitives, changes later proposal probabilities and controls expanded primitive size/cost. TA-01 adds a more specific source/destination split, shuffled prior and smaller macro cap; those are useful experiment refinements. They do not create a second library-learning mechanism or new representable primitive functions. Reject a second novelty count; retain the conditional symbolic gate under one family.

2. **[P2] Make abstention observable rather than an oracle response to hidden outcomes** — [report line47](brainstorm-ta001.md#L47). An identical-descriptor pair with opposite outcome mechanisms proves that a universal successful router is impossible. It does not let the router know that an unseen descriptor is ambiguous. Require a pre-frozen abstention rule derived solely from source-bank conflict/support or explicit out-of-support detection. Otherwise the test passes only by giving the decision process privileged knowledge of the synthetic generator. Abstain-to-default also does not eliminate regret of that default. Test coverage and nontrivial routing alongside ambiguity rejection so “always default” cannot pass as successful transfer.

3. **[P2] Pay for both destination bundles before reporting oracle regret** — [report lines47–49](brainstorm-ta001.md#L47). Three fits, one for each policy's selected bundle, do not necessarily train both alternatives. If learned/global/random policies all select direct-repeat, best-destination-bundle regret is unknown without a fourth fit. The cheapest repair is one common frozen fit per destination bundle, shared by all three policies and the oracle diagnostic: two distinct destination fits, one common evaluation population/seed/learner, collision consumed without redraw. If policy-specific retraining is intended, budget every missing oracle alternative separately. Destination labels may evaluate the frozen router afterward; they must not choose or recalibrate its route.

4. **[P2] Separate source model training from the performance-bank labels** — [report line45](brainstorm-ta001.md#L45). “128 mature source queries and two bundle fits” does not specify which examples fit each bundle and which independent chronological queries estimate its utility. In-sample performance can manufacture a confident but wrong family-selection label. Declare source train→validation→bank-freeze chronology and preserve empty/mature queries. At task-level routing, three synthetic mechanisms provide only **three task-level descriptor/performance examples**, not384 independent router examples. A query-level router would be a different FB04-like mechanism and must be named/budgeted accordingly. Keep TA-03 deferred beyond an analytical mechanics gate until this unit and chronology are explicit.

## Source and implementation checks

**LILO/TA-01.** ICLR2024 publication status and string/scene/graphics scope are supported. Its compression uses Stitch branch-and-bound over lambda abstractions, followed by AutoDoc and synthesis; a simple typed anti-unifier without LLM/AutoDoc is a local adaptation. The author `stitch_proposer.py` calls `stitch.compress` with arity/iteration bounds (lines188–206), infers new-production types (154) and re-estimates grammar probabilities from rewritten frontiers (161–165). Thus changing a proposal prior is source-backed; the ten-minute/512MiB local experiment is not a measured LILO bound. No upstream code was executed. [Conference paper, §3/A.4](https://proceedings.iclr.cc/paper_files/paper/2024/file/819cebb05f993840e8a52d7564c5c282-Paper-Conference.pdf), [author compressor wrapper](https://raw.githubusercontent.com/gabegrand/lilo/main/src/models/stitch_proposer.py).

**MPL/TA-02.** The paper explicitly represents whole metaprograms, including data-driven transformations such as MemorizeAll, Recurse and AntiUnify; the evaluated model uses MCMC and a prior sensitive to both the metaprogram and resulting program complexity. It does not demonstrate learning an ecommerce edit-transition prior from source before/after feature programs. TA-02 is therefore a legitimate extrapolation only when that distinction stays explicit. The paper lists its full reproduction package on OSF and supporting author libraries for program induction, term rewriting and type inference. I inspected the listed repositories/documentation but did not fetch the full OSF package or verify the complete MPL runtime. The Nature page was inaccessible; the author-hosted paper was readable. [Paper, Methods Eq12 and Code availability](https://colala.berkeley.edu/papers/rule2024symbolic.pdf), [author program-induction library](https://github.com/joshrule/program-induction), [term-rewriting library](https://github.com/joshrule/term-rewriting-rs).

**Relatron/TA-03.** The paper's task homophily explicitly uses labels; its affinity probes include fitted ridge/LDA heads, TabPFN validation and label timeline summaries. Calling a probe training-free or model-free does not make it outcome-free. The author's README requires contacting the authors for its precomputed performance bank or paying for large architecture searches. Those limitations are accurately acknowledged in TA. The README is available; specific implementation files for task-feature evaluation returned cache misses, so no source-level selector reproduction acceptance is claimed. [Paper, §4.1](https://arxiv.org/html/2602.22552v1), [author README, performance-bank section](https://github.com/amazon-science/Automating-Relational-Machine-Learning#tasks-requiring-performance-bank).

**PluRel and RT.** PluRel separates schema, foreign-key connectivity and conditional feature mechanisms. Author config exposes database, SCM and DAG settings, timestamp ranges and temporal parameters. It does not supply the proposed three-mechanism purchase-event generator or certify its causal prefix/target contract. The tiny local generator remains our adaptation and must preserve second-level ties, maturity, no hidden IDs and target-independent candidate construction. RT explicitly lists recommendation/link prediction as unsupported and reports strong reliance on past task-table labels; rejecting its headline as a drop-in REES ranking baseline is supported. ## Minimal repairs and falsifiers

**TA-01 / FA04 — merge, conditional symbolic gate only.** Expanded-AST equality should check NULLs, units, global timestamp peers, metadata resolvers and fitted constants before proposal identity/closure. Fix both expanded size and expanded-node work; one large macro call is not one cheap opportunity. Cap total proposed attempts as well as complete evaluated ASTs; otherwise arbitrarily many invalid bindings can precede512 valid evaluations. Charge induction, archive creation, alias expansion, rejected/duplicate proposals and every specification evaluation. A shuffled prior should preserve typing, eligible macro inventory and complexity; a shuffle that destroys legality mainly tests the type checker.

Cheapest useful test: two source corpora contain a recurring typed shape, while the held compositional family is absent even after role renaming and expansion equivalence. Compare the same legal universe under flat and induced priors and one type-preserving shuffled prior. Show a discovery difference at equal expanded effort and a case where a newly bound unavailable action is rejected. No predictive fits or real source rows are needed. A negative finite search result rejects this recipe/cap, not the universal usefulness of library learning.

**TA-02 — retain as a distinct needs-pilot adaptation after specification repair.** Whole-program, meaning-changing edits differ from HYP002's static grammar and HYP117/118's conservative equivalence refinement. They also differ from FA04 when macro inventory stays fixed and the transferred object is a transition prior. However, “learn a distribution” needs a finite estimator: define source before/after programs or canonical edit traces, smoothing, applicable edit sites and parameter domains. Input/output feature specifications can admit multiple edit traces; using the known intended destination answer to choose one would turn the test into a seeded answer lookup.

Use shared seeds and the same eight legal edits for learned and uniform controls, with one held-out **reachable** composition. A count→distinct edit should distinguish two identical logged views (raw2/distinct1), while a held-out action/grain composition must satisfy independent unit/support/metadata expectations. Split the literals supplied during search from undisclosed verification literals; all controls receive the same feedback. A task provably beyond the two-edit support is an abstention/out-of-support check, not evidence that the learned prior transferred badly. The scratch enumerator tests the value of seed-plus-edits; learned versus uniform edits isolates the prior. Freeze both expanded-program and metaprogram/edit cost; do not quietly replace MPL's two-level prior with cheap edit count and call it a reproduction.

**TA-03 — defer fits; analytical identifiability gate is ready to specify.** Let one descriptor d occur in two worlds with bundle utilities `(1,0)` and `(0,1)`. A deterministic router must return the same choice on d and fails in one world. A randomized route choosing A with probability p has regrets1−p and p, so its worst-world regret is at least1/2. This is a literal mathematical consequence, not synthetic training performed here. It demonstrates a limit, not a detector. To test operational abstention, put known conflicting source-bank entries at d and freeze a conflict/support threshold before a held task; separately test an unseen mechanism at the same d and report that correct abstention cannot be guaranteed from descriptors alone.

Define “repeat fraction” as a strict-past observable statistic with a precise event/purchase grain; never future repeat-target fraction. Build domains/bins/scalers/router/default from legal source state before M, complete all source labels and bank computation before M, and never backdate it to earlier destination queries. Source outcomes can be available while destination query outcomes remain closed. If downstream destination models later train on authorized synthetic train labels, explicitly separate that access from the **router's** no-destination-label promise. Model training, validation evaluation, bank selection and oracle diagnostic each have their own chronology and paid looks.

Keep one target/horizon/population and two fixed bundles across the synthetic tasks, predeclare task weights and full-Y ranking regret, and record abstention coverage plus regret on routed and full populations. A single held schema/mechanism task and three source tasks provide a sanity test, not a reliable learned transfer estimate. HYP014's unavailable pretrained ranker is not revived by citing Relatron; the bank acquisition/build cost remains real. Compared with FB04's within-domain query routing and NB-F04's label-free reliability allocation, TA-03 retains a possible delta as a **cross-task frozen source-outcome policy**, subject to the identifiability limits above.
