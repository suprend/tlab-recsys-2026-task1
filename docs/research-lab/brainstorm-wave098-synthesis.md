**A — только HYP-061, необязательное проектирование источника.** Предложен ограниченный обход общей view-аудитории: до четырёх R20 seeds, целые пользовательские профили degree≤32, полный отказ от seed при аудитории>512, вычитание query user до guards/support/norms. На общем discovery pool сравниваются shrunk co-count c²/(c+10) и его cosine-нормировка с одинаковыми support floor, seeds и shrink. Original C0 исключается до top20. Это точность объявленного фильтрованного графа, не полного исходного графа. HYP-062 означает activity weighting; данный контраст её не проверяет. Прежние extraction/projection для заданных C∪H не извлекают автоматически все товары seed-аудитории и не делают новый retriever готовым.

Root сохранил A как optional SOURCE-design, реальный retrieval-пилот не принят к исполнению этой волной. Локальная граница 4×512×32 edge visits на запрос не ограничивает глобальные сканирования, degree/norms, hashing, память или I/O. Полная стоимость неизвестна; предложенные author limits не являются измерениями. До реализации остаются точный tie rule и различающие границы query-user removal. Ни этот дизайн, ни положительный retrieval Recall не заменяют исходный опыт автоматизации признаков или обещают NDCG-выигрыш.

**B1 — HYP-053/TLAB-004, диагностическая oracle-карточка.** Для каждого q нужны собственные m=|Y| и h=|Y∩C|: oracle@20 равен отношению сумм 1/log2(r+1) до min(20,h) и min(20,m). Общие hits/121 не определяют средний oracle NDCG. Для positive-query macro справедливо 1−M=(1−O)+(O−M); при all-query-zero верхняя граница — p, поэтому p−M_all=(p−O_all)+(O_all−M_all). Уменьшенное покрытие может ограничивать NDCG, но при h≥min(20,m) oracle равен 1. Ordering residual неизвестен без scorer на тех же Q/C/Y; другой календарь B/W подставлять нельзя. [Карточка принята Root после независимой проверки](../backlog-reviews/candidate-oracle-diagnostic.md): в selection4000Q/73positive O=0.6942312761, B2027 M=0.4504012777, 1−O=0.3057687239, O−M=0.2438299984. Категорийные8–10 — отдельная популяция; их ordering residual остаётся UNKNOWN, четыре oracle-ячейки сверены точно. Это не достижимый или причинный gain и не продвижение C1 вместо исходного критерия. Две ошибки audit harness и первый monitor PermissionError с неизвестным terminal/reap сохранены; они не признаны дефектами карточки.
