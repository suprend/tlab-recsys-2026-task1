## Actionable findings

**P2 — Separate five sampler calls from five physical catalogue passes.** [Report line29](brainstorm-ra002.md#L29) and [line45](brainstorm-ra002.md#L45) turn four predictors plus a denoiser into exactly five full-catalogue passes/100,000 item slots. The outer [author sampler](https://raw.githubusercontent.com/Hugo-Chinn/PreferGrow/main/sampling.py) supports five `score_fn` invocations. The [model wrapper](https://raw.githubusercontent.com/Hugo-Chinn/PreferGrow/main/model/utils.py) calls `forward_eval(..., personalized_strength)`; the paper also defines conditional/non-preference contrast. I could not fetch the transformer implementation, so the number of physical branches and catalogue projections inside that call is unverified. Freeze a plain conditional adapter with one vector per invocation, or count every guidance branch, history encoding, projection and cache miss. The logical call count alone cannot admit the stated physical budget. This is a documentation/readiness defect, not a measured overrun.

**P2 — Make the orientation oracle asymmetric.** [Report line39](brainstorm-ra002.md#L39) asks its uniform-replacement fixture to check row/column orientation. Uniform replacement is symmetric: a transpose bug passes that fixture. Add the asymmetric rank-one fixture below and declare `P[j,i]=Pr(next=j | current=i)`. Keep the uniform fixture for the actual proposed mechanism; the asymmetric example is an audit oracle, not a new experiment family.

No P0/P1 defect was established. The author already forbids hidden target seeds, clipping, backdated state, refills and inferred dislike labels. The remaining points below are explicit conditions for a later proposal, not claims that those prohibited actions occurred.

## RA2-01: retain, refine, then source-free gate

[SEATER v2](https://arxiv.org/html/2309.13375v2) supports a balanced collaborative identifier tree and autoregressive path probability; its original preprint is from 2023, so the report correctly identifies the 2024 revision/publication rather than inventing a new 2024 method. The [model](https://raw.githubusercontent.com/Ethan00Si/SEATER_Generative_Retrieval/main/model/SEATER.py) gathers current-node children, masks padding, normalizes sibling scores and adds accumulated beam log-probabilities. It also copies encoder memory across beams and reorders decoder caches. Thus `32×8×6` can bound child-score slots for the proposed constrained tree; it does not bound attention, cache movement, or total neural work.

The exact literal calculation passes: A=.6 with children .5/.5 produces .3/.3, whereas B=.4 with .99/.01 produces .396/.004. Beam1 prunes the best leaf; beam2 retains it. This is a counterexample to equating branch mass with best-leaf score. It establishes neither learned relevance nor a gain over flat classification. The next source-free check should implement legal-leaf exhaustive scoring and the actual beam wrapper on at most16 tiny states, including equal scores, too few children, EOS, invalid codes and collisions. No such decoder was executed in this review.

Author first-level beam padding can retain duplicated node addresses with `−inf` scores when beam width exceeds available children. The adapter must discard invalid/nonfinite paths and deduplicate product IDs before applying the source quota. It must expose native underfill. A known leaf lost through pruning is a search miss, distinct from a product absent from the fitted source dictionary.

[ETEGRec model code](https://raw.githubusercontent.com/RUCAIBox/ETEGRec/main/model.py) offers constrained generation only when an allowed-prefix function is supplied; its default custom beam searches codebook tokens. [Mapping code](https://raw.githubusercontent.com/RUCAIBox/ETEGRec/main/trainer.py) adds collision suffixes to catalogue codes. Unique mapped codes do not make every Cartesian code combination a catalogue item. An ETEG adapter needs an explicit valid-code trie or a declared invalid-code rejection policy, with its own branch factor, suffix depth and mapping costs. It cannot inherit SEATER’s eight-child budget merely because both methods generate identifiers.

MB04 already proposes jointly learning tokenizer and decoder, with complete-code scores on fixed C; it explicitly separates free beam retrieval. RA2-01 freezes the hierarchy and studies discovery/pruning under a new source quota. That decoding-level delta is useful and is not the same experiment. It belongs under the same generative family, with joint tokenizer updates treated as a later refinement, not a second “joint codes” novelty count.

Before any learned reservation, specify the exact adaptation: history bucket limit and members per bucket, encoder/decoder dimensions and layers, objective and loss weights, optimizer updates and checkpoint policy. Author SEATER includes more than generation cross-entropy; omitting its alignment/ranking losses is a declared adaptation, not a reproduction. Same-second pooling must be invariant to peer order, including history truncation: retain/drop whole boundary buckets or use a declared invariant reduction. Sorting peer IDs into a sequence does not satisfy that requirement.

The [tree builder](https://raw.githubusercontent.com/Ethan00Si/SEATER_Generative_Retrieval/main/utils/build_tree.py) recursively runs constrained clustering with `n_jobs=-2` and does not pass the proposed one-initialization/20-iteration limits. The wrapper must enforce those limits and charge every recursive node/solver call, source scan, embedding fit, serialization and catalogue validation. A six-level/node-count ceiling alone does not bound clustering time. The report’s inclusive CPU/RSS stop remains the final admission rule; exceeding it must not trigger source subsampling or shallower substitute codes.

Minimal later falsifier: exact decoder/tree versus bounded beam at equal legal support first. If pruning alone loses unacceptable leaf coverage or the build cannot cover declared V within its cap, stop before fitting a comparison. Only afterwards compare the full path procedure with the flat classifier under matching inputs, V, mature queries, fit limits and source quota. That contrast cannot isolate beam search as the cause of a quality change.

## RA2-02: refine the semantics and defer learning

[PreferGrow v1](https://arxiv.org/html/2509.26063v1) and the active [PairWise class](https://raw.githubusercontent.com/Hugo-Chinn/PreferGrow/main/graph_lib.py) support idempotent replacement and reference-conditioned ratios. The active class is around line640; an earlier similarly named block is inactive. Its reductions/inverse transform operate on one N-vector, so an N² table is not required. This does not remove all-catalogue training or neural projection cost.

Exact stdlib arithmetic independently confirms the report’s uniform Bayes example: reference b gives `(16/29,12/29,1/29)`, unlike forward replacement `(1/6,2/3,1/6)`. The no-self N=3 replacement matrix is not idempotent. For the stronger orientation test use `E=μ1ᵀ`, `μ=(3/5,3/10,1/10)`, α=1/2 and the same p0/reference. Correct posterior is `(8/15,13/30,1/30)`; incorrectly reading the column gives `(12/17,39/136,1/136)`. These exact answers differ and detect transposition.

Positive predicted ratios need not imply a valid reverse distribution. With uniform N=3, α=1/2, reference b and ratios `(10,1,1)`, the inverse produces `(16,−2,−2)` and signed reverse weights `(8/3,−4/3,−1/3)`, whose sum is1. Clipping removes negative mass5/3; renormalization then changes the transition. That signed mass is not a valid probability distribution or a TV error bound. The [active categorical sampler](https://github.com/Hugo-Chinn/PreferGrow/blob/main/catsample.py) takes `log(weights+1e−9)` without a validity assertion. The proposed adapter therefore needs fail-before-log/sampling/top-k checks, including the final denoiser. An epsilon does not repair meaningful negative weights. Clipping/softmax would require a separately named adaptation and control.

One final vector from one realized reference is a conditional posterior, not generally the marginal clean preference vector. A second exact example has N=2, α=1/2, p0=(.6,.4): conditioning on a yields `(9/11,2/11)`; conditioning on b yields `(1/3,2/3)`, reversing the winner. Top20 from one trajectory remains a legitimate proposed procedure, but its ranking semantics and seed sensitivity must be named. The report correctly confines `exp(−6)` to pre-reversal initialization error; it cannot certify final ranking accuracy.

The source-free gate must test orientation, reverse/forward distinction, ratio reference normalization, finite/nonnegative mass and deterministic query seeding. Use one precommitted seed independent of current Y, with one trajectory and no retries after a bad reference. A one-step comparison must use a declared label-blind initial state and endpoints. Author `get_one_step_score` corrupts supplied x0 and scores that item; it cannot become the label-blind retrieval control. No current positive, future popular item or validation result may choose the seed/reference/schedule.

For later training, ratio and direct-classifier controls need the same covered query-positive weighting and identical excluded-query accounting. A query whose entire Y lies outside V supplies no covered categorical target; report its exclusion from fitting while retaining it and all its positives in full-Y evaluation. Reference conditioning and extra passes must change eligible admissions to justify additional retrieval work. Five versus one logical calls is a cost frontier comparison; a separately capped equal-physical-work control can allocate its budget differently, but cannot quietly give the ratio method five times the work.

## Shared availability, comparisons and stopping

Keep four distinct supports: as-of legal universe U(t), trained source catalogue V, valid/scored or visited leaves/items, and admitted final C. Source-OOV, beam/invalid-code loss, quota displacement and ranker loss have different causes. Purchase repeats stay legal. Fitted embeddings/tree/mapping must exist before the downstream training anchors; complete 24h training targets must mature before fitting, and the resulting state must be available before quality queries. Reject late inserted catalogue items, target-leaf fixes and backdated caches. Daily snapshots and history cutoffs must use whole timestamp-second peers; diffusion noise is not event time.

Retain native `P180+R20+source20`, matched-source20, and current `P200+R20` comparisons. Specify rank ownership, deterministic technical ties, eligibility filters, dedup order and fallback identically before Y. The 20 displaced global ranks are181–200, not an uncharged extra source. Report no-refill actual C sizes and source admissions; separately apply predeclared label-blind truncation to a common actual size. Classifier/path/ratio controls need equal eligible source support V∩U(t); include a same-support popularity diagnostic while preserving the official current policy. Equal requested quotas alone are insufficient.

Keep full-Y candidate Recall with gained/lost **query-product pairs**, macro/micro and U/source coverage. A query-hit statistic counts a query once; it must not replace pair coverage when several purchases occur. Empty mature queries and cold targets remain represented. No target-based source choice, size matching or source reservation is allowed. Current heldout remains closed; all learned work needs a new reviewed development reservation.

Use one selected family only: literal gate≤16 states/5CPUmin/512MiB; prospective source gate100Q/2threads/6GiB/inclusive30CPUmin; prospective learned gate≤120CPUmin with the stated fits. Charge a clustering job once to an explicitly named inclusive phase, and show the end-to-end total; “additional paid clustering” is not unlimited allowance outside120 minutes.
