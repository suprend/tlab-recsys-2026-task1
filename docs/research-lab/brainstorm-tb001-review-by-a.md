## TB1: retain synthesis, do not count an old witness as novelty

It explicitly models implemented behavior and warns that intended semantics still require validation. Its [author repository](https://github.com/jonayerdi/genmorph) targets Java and depends on separate test/mutation tools. TB's typed-event grammar and minimal portfolio are adaptations, not an already supplied feature-AST compiler or a reproduction within60CPU seconds.

The proposed share arithmetic is correct:1/2→2/3under a numerator duplicate and1/3under a denominator-only addition. The distinct wording needs repair: **copying an existing eligible event always changes exact distinct count by0**. Adding a new entity changes it by1; that is a different transformation/precondition. Relations must preserve grain/action/window/category/coverage validity, while NULL/unknown states receive separate witnesses.

The off-C denominator adversary is already explicitly present in rounds018/045. Killing it demonstrates conformance, not that synthesis found a new failure missed by the fixed bank. The new mechanism must generate AST-specific relations/portfolios instead of selecting more fixed laws. Freeze development mutant families, then evaluate against independently authored **held-out families**. A mutant used in relation fitness/portfolio choice is not fresh evaluation evidence. Deduplicate equivalent mutant phenotypes; report surviving known-non-equivalent defects and observed false alarms, not universal correctness.

**Fairness/cost fix.** The expression4×9×64=2304counts single executions only if64means all source+followup executions, not64pairs. Otherwise pairs require4608before oracle/filter/shrinking work. Keep the proposed **total2304actual interpreter-call/60CPU-second/256MiB ceiling**, reducing cases as needed; cache reuse may be common to all strategies, with cache construction charged. Fixed/random and synthesis get equal declared access to semantics/mutants and comparison budget; report preparation separately. No Java dependency/toolchain migration is justified for this first stdlib design.

## TB2: define the actual gate and the evaluation claim

The [ICML2024 c-STG paper](https://proceedings.mlr.press/v235/sristi24a.html) starts with Bernoulli selection, then uses relaxed stochastic gates parameterized by context. The inspected [author implementation](https://github.com/Mishne-Lab/Conditional-STG) uses clipped Gaussian noise during training; its deterministic evaluation gate is clipped μ, generally **continuous attenuation**, not automatic binary inclusion or abstention. A sigmoid variant can leave all gates strictly between0and1. A binary threshold or feature-emission interface is a new declared adaptation. The [inspected sigmoid selector](https://github.com/Mishne-Lab/Conditional-STG/blob/main/models/fc_stg_layered_parametric_modular_sigmoid.py#L67) codes erf((μ/σ)√2), while the paper CDF needs erf((μ/σ)/√2): at μ=.25,σ=.5 these yield.841345versus.691462. This is a static observation of that file, not every author experiment; no code was executed here.

The balanced-bit fixture is sound: a singlex1orx2predicts75%, contextual choice100%. A dense tree receivingx1,x2,zalso achieves100%, so the fixture establishes neither extra information nor unique expressivity. The real new question is whether context-dependent sparsity/regularization helps at finite support/cost. This is different from deterministic capability masks and existing global selection. Unsupported arithmetic must still be rejected before learning; a low learned gate is not proof a feature is invalid or causally irrelevant.

**Learner confound:** compare c-STG against the same dense predictor receivingf,zand global gates with the same context exposure/preprocessing. The inspected forward path sends context directly to the dense predictor only when gates are disabled; copying it changes the information path too. A syntheticx≡0,y=zcase exposes that: gatedxalone remains0, whereas a dense predictor seeingzcan predict. Record additional hypernetwork parameters and update counts; fixed width/epochs alone does not equalize compute. Strong boosting with the samef,zis an external package reference. If gated features are then fed into a separately fitted booster, that adds a fifth fit and another model lifecycle: the stated four-fit protocol currently supports the joint neural predictor only. Do not mix these claims. A mask/continuous gate companion can re-expose information omitted by the gate, so sparsity must be defined over the actual inference inputs and active multiply-adds.

**Cheapest falsifier:** synthetic μ below0, inside(0,1), and above1; test stochastic clipping, deterministic continuous output, optional explicit hard threshold and the exact penalty/CDF. The helper checks are sufficient to reveal specification mismatches, not native engine compatibility. Then a future no-quality resource gate with declared dummy labels and no optimizer update. Keep the four-fit/four-look inclusive60CPU-minute cap as an alternative proposal, with equal per-neural-arm ceilings and paid preparation/inference/failures. Add positive-query support minima and frozen observation regimes before pilot;2,000totalQdoes not guarantee informative purchase support. Defer fits until gate semantics and a concrete robustness estimand are frozen.

Coarse binning matters mathematically: splitting one equal-mass bin into two changes normalized product weight, even with unchanged underlying rows. Two underlying fits suffice only for one shared B/B+f pair trained before both environments; separate environment-specific pairs require four. All candidate selectors share identical artifact/outcome access, looks and user-cluster uncertainty. A selector's practical value needs later independent outcome evidence; the current literal arithmetic alone supports only descriptive standardization. Refinement is required before any promotion policy.

## TB4: a tested reversal statistic, not a true-radius bracket

[Pereira/Said/Santos, RecSys2025](https://arxiv.org/pdf/2508.05398) separates logging and sampling using nearly fully observed KuaiRec preferences, then studies model-ranking agreement. The [linked author repository](https://github.com/LatinUFMG/recommenders-sampling) is real. REES46 lacks their exposure/ground-truth basis. TB's channel-specific reversal rule is its own stress-test decision operator, not a paper-established estimator of logging robustness or transfer failure.

The three-query K1example is valid: gain+1/3→−1/3after two of six candidates are removed with a pre-fixed ID schedule. But **nested label-blind deletion does not make gain monotone**. My five-query literal has threef-wins/twoB-wins: removing distractors in twof-winning queries gives+.2→−.2at20%removal; additionally removing distractors in the twoB-winning queries gives+.2againat40%. Thus a grid can miss an earlier reversal that later recovers. A last-positive/first-negative interval does not bracket the true first reversal without an additional proved monotonicity assumption.

Call the statistic “smallest **tested** level with sign reversal.” If no level reverses, say “none among tested levels,” not a robust lower bound. Freeze handling for cleanΔ≤0, ties, numerical tolerance and uncertain small support. Pinned hash thresholding should produce nested deletion sets and report actual per-query/total removal fractions; monotonicity still does not follow. Separate view/cart history thinning fromCsubsampling. Keep originalQeligibility andCfor history-only tests, annotate observation coverage consistently, and do not silently regenerate recent-source candidates. ForCsubsampling, keep the same reducedCfor both models and fullYdenominators; declare whether candidate source/rank features remain original or are recomputed, since that changes treatment.

**Cheapest falsifier/cost:** the nested reversal fixture above plus emptyC/removedpositive/zeroY/tie cases, all label-blind by construction. The proposed2models×7cases×2,000Q×220C=6.16million score-row upper bound is correct, but it does not bound source event scans/materialization. Add source-window/event-row limits and pay all recomputation/inference/failures inside60CPU minutes;0refits only if the fixed model pair already exists under a separate paid plan. Sevenpaired looks remain seven declared treatment looks, not one independent confirmation. For now merge descriptive sensitivity intoTLAB-013. Retain a new selector HYP only after a prospective study can establish that its rule adds decision value beyond clean gain and the ordinary fixed stress grid.
