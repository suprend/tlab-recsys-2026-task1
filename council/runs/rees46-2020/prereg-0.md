# Совет над H+, REES46 2020: prereg-0

Записано 21.10.2026, после кода и двух шумовых подгонок, до любой подгонки с признаками совета и до чтения
S0-select. Числа — `prereg-0.json` рядом; контракт — `contract.md`.

## Проверка пути

`path_Hr_full_val_s0` (H+r, `full_val`, train → val, зёрна 2026/0) совпала с `pl20_Hp_s0` на всех 44 334
запросах: max|Δ| = 0 по NDCG, Recall и их покупочным версиям. Пик 21.0 ГБ, подгонка 648 с. Запись — в
`reads.jsonl` (только разности).

## Шум прокси и мощность вычитания

- Две подгонки H+r в рецепте `plan` (T_fit → S0, половина A, зёрна 2026/0 и 7/1): 15 759 запросов
  S0-explore, 13 958 пользователей. σ_q = SD(y₁ − y₂)/√2 = 0.0634; дизайн-эффект по пользователям 1.0007;
  |сдвиг среднего между зёрнами| 0.00032. Это единственное чтение S0-explore (`broker.noise_explore`).
- Нулевая репетиция (`design.rehearse`, замкнутая форма, 2000 симуляций, n = 15 605 ожидаемых запросов
  S0-select): мощность номинации вреда −0.0005 = **0.52**; интервал SD t пустых [0.367, 0.848], медиана 0.68;
  доля ложных номинаций на нуле 0.011. SE_boot ≈ 0.00015.
- Чувствительность: с шумом уровня подгонки σ_fit = σ_q/√n мощность 0.34 (интервал SD t [0.49, 0.91]);
  при вреде −0.001 мощность 1.0.
- **Гейт мощности не пройден (0.52 < 0.8).** По контракту вычитание описательное: **SEL = ALL_P по
  построению**, номинация и подтверждение D не запускаются, рука SELpl не нужна. План остаётся ради β семейств,
  калибровки (описательно) и механизмов (близнецы, §3.3).

## Режим логирования

Доли просмотров/корзин/покупок, `rees46.duckdb`, по дням. Средние по разделу: S0 — корзины 0.0536, покупки
0.0159; C_val — 0.0500 и 0.0213; C_test (основные дни) — 0.0447 и 0.0202. Наибольшее отношение средних 1.34 ≤ 1.5:
**условие выполнено**. По отдельным дням оно нарушено: покупки 10–17.02 до 1.9× (всплеск к 14.02), корзины
24–29.02 ниже до 1.7×. Трактовка «по средним раздела» выбрана после взгляда на дневные доли; при трактовке «по дням»
итог тот же — SEL = ALL_P (уже следует из гейта мощности), так что выбор на выводы не влияет.
